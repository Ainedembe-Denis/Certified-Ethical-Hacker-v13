## 1. Attack Methodology Stages

Hacking a web server typically follows a preplanned attack methodology:
1. **Information Gathering**
2. **Web Server Footprinting**
3. **Website Mirroring** (copying content for offline browsing)
4. **Vulnerability Scanning**
5. **Session Hijacking**
6. **Web Server Passwords Hacking**

---

## 2. Information Gathering

The first step is to collect as much information as possible about the target's domain name, IP address, and autonomous system number.

### Information Gathering Tools
* **who.is** ([https://who.is](https://who.is)): Domain whois search, whois IP lookup.
* **Whois Lookup** ([https://whois.domaintools.com](https://whois.domaintools.com))
* **Whois** ([https://www.whois.com](https://www.whois.com))
* **Domain Dossier** ([https://centralops.net](https://centralops.net))
* **Subdomain Finder** ([https://pentest-tools.com](https://pentest-tools.com))

### Gathering from `Robots.txt`
If a website owner improperly writes a `robots.txt` file, attackers can discover restricted directories, passwords, and hidden links. Attackers download it via the browser or using the **Wget** tool.

## 3. Web Server Footprinting & Banner Grabbing

Extracts valuable system-level data like account details, OS, software versions, and database schemas.

### Telnet
Connects to a specific port and probes HTTP servers without encryption or authentication.
* *Command:* `# telnet www.moviescope.com 80` -> press Enter.
* *Follow up:* Type `GET / HTTP/1.0` -> press Enter twice.

### Netcat
**Source:** [https://netcat.sourceforge.net](https://netcat.sourceforge.net)
A reliable back-end networking utility.
* *Command:* `# nc –vv www.moviescope.com 80` -> press Enter.
* *Follow up:* Type `GET / HTTP/1.0` -> press Enter twice.

### httprecon
**Source:** [https://www.computec.ch](https://www.computec.ch)
Advanced web server fingerprinting that analyzes header ordering and status codes by executing specific HTTP test cases:
* Legitimate GET requests, >1024 bytes GET requests, non-existing resource requests.
* `HEAD`, `OPTIONS`, `DELETE`, `TEST` methods.
* Non-existent protocol versions like `HTTP/9.8`.
* Attack patterns like `../` and `%%`.

### Uniscan
**Source:** [https://sourceforge.net](https://sourceforge.net)
Performs static, dynamic, and stress checks. Compiles automated Bing and Google searches for specific IPs into a comprehensive report file.

### Other Footprinting Tools
* **Netcraft** ([https://www.netcraft.com](https://www.netcraft.com))
* **ID Serve** ([https://www.grc.com](https://www.grc.com))
* **Nmap** ([https://nmap.org](https://nmap.org))
* **Ghost Eye** ([https://github.com](https://github.com))
* **Skipfish** ([https://code.google.com](https://code.google.com))

---

### Footprinting with AI (ChatGPT)
Attackers leverage AI to automate footprinting tasks by combining tools:
* **Prompt:** *"Perform webserver footprinting on target IP 10.10.1.22"*
* **AI Output:** `nmap -sV 10.10.1.22 && whatweb 10.10.1.22 && nikto -h 10.10.1.22`
*(This executes Nmap for version detection, WhatWeb for identifying web technologies, and Nikto for comprehensive vulnerability testing).*

* **Netcat with AI Prompt:** *"Perform webserver footprinting on target IP 10.10.1.22 with netcat"*
* **AI Output (Heredoc syntax):**
  ```bash
  nc -v 10.10.1.22 80 <<EOF
  HEAD / HTTP/1.1
  Host: 10.10.1.22
  EOF
  ```

---

### IIS Information Gathering using Shodan
Shodan search filters specifically targeting IIS servers:
* **All IIS Servers:** `http.title:"IIS"`
* **By Company Name SSL:** `Ssl:"Company Inc." http.title:"IIS"`
* **By Common Name SSL:** `Ssl.cert.subject.CN:"company.in" http.title:"IIS"`
* **Geographical:** `http.title:"IIS Windows Server" country:"US"`
* **By Version/Port:** `http.title:"IIS7" port:80`
* **By Subnet:** `http.title:"IIS7" net:"<IP_address>/24"`
* **Broad Search:** `http.title:"Internet Information Services"`

## 4. Nmap Enumeration & Detection

### Enumerating User Accounts (Apache `mod_userdir`)
Exploiting `mod_userdir` (which allows URI access like `~/username/`):
* **Initial Scan:** `nmap -p80 --script http-userdir-enum <target>` *(Uses default `usernames.lst` at `/nselib/data/`)*
* **Custom Scan:** `nmap -p80 --script http-userdir-enum --script-args userdir.users=<Wordlist>.txt <target>`

### Bypassing Detection with Custom User Agent
* **Command:** `nmap -p80 --script http-brute --script-args http.useragent="<User_Agent>" <target>`

### Various Nmap Scripting Engine (NSE) Commands
* **Virtual Domains:** `nmap --script hostmap-bfk <host>`
* **HTTP TRACE Detection:** `nmap --script http-trace -p80 <host>`
* **Harvest Emails:** `nmap --script http-google-email <host>`
* **WAF/IPS Detection:** 
  `nmap -p80 --script http-waf-detect --script-args=”http-waf-detect.uri=/testphp.vulnweb.com/artists.php,http-waf-detect.detectBodyChanges” www.modsecurity.org`
* **WAF Fingerprinting:** `nmap --script=http-waf-fingerprint -p80,443 <host>`
* **App Enumeration:** `nmap --script http-enum -p80 <host>`
* **Robots.txt:** `nmap -p80 --script http-robots.txt <host>`
* **Basic Version Info:** `nmap -sV -O -p <target IP address>`
* **Frontpage Login:** `nmap <target IP address> -p 80 --script = http-frontpage-login`
* **Password Enum:** `nmap --script http-passwd --script-args http-passwd.root =/ <target IP address>`

## 5. Finding Default Credentials & Content

### Finding Default Credentials
Attackers target default admin interfaces using port scanning, then use Metasploit or lookup databases:
* **cirt.net** ([https://cirt.net/passwords](https://cirt.net/passwords))
* **FortyPoundHead** ([https://www.fortypoundhead.com](https://www.fortypoundhead.com))
* **Default Password Info** ([https://default-password.info](https://default-password.info))
* **Router Passwords** ([https://www.routerpasswords.com](https://www.routerpasswords.com))
* **DefaultPassword** ([https://www.defaultpassword.com](https://www.defaultpassword.com))

### Finding Default Content
* Targeting **administrators' debug and test functionality**.
* Accessing **sample scripts and APIs** deployed on HTTP ports.
* Looking for **server installation manuals**.
* **Tool:** `Nikto2` ([https://cirt.net](https://cirt.net)) identifies default contents and vulnerabilities.

## 6. Directory Brute Forcing

A web server responds to directory requests by returning the default resource (`index.html`), an error (`403 Forbidden`), or a **listing of directory content**. Improper access controls lead to web root exposure.

* **Tool - Dirhunt** ([https://github.com](https://github.com)): Optimized crawler that finds "index of" modes and directories with false 404 errors or empty index files.
* **Tool - Sitechecker Website Directory Scanner**

### Directory Brute Forcing with AI (ChatGPT)
* **Prompt:** *"Perform a directory traversal on target url https://certifiedhacker.com"*
* **AI Output:** 
  `gobuster dir -u https://certifiedhacker.com -w /usr/share/wordlists/dirbuster/directory-list-2.3-medium.txt`

## 7. Vulnerability Scanning & Exploitation

Automated scanning to reveal weaknesses in active systems, services, and apps.

### Vulnerability Scanners
* **Acunetix WVS** ([https://www.acunetix.com](https://www.acunetix.com)): Detects SQLi, XSS. Crawls HTML5, SOAP, AJAX. Checks CAPTCHA and 2FA pages.
* **OpenText Fortify WebInspect** ([https://www.opentext.com](https://www.opentext.com))
* **Tenable.io** ([https://www.tenable.com](https://www.tenable.com))
* **ImmuniWeb** ([https://www.immuniweb.com](https://www.immuniweb.com))
* **Invicti** ([https://www.invicti.com](https://www.invicti.com))

### Nginx Vulnerability Scanning (Nginxpwner)
**Source:** [https://github.com](https://github.com)
A Python tool finding Nginx misconfigs (improper permissions, insecure defaults).
1. `nano /tmp/pathlist` (add crawled URLs and exit).
2. `python3 nginxpwner.py <target_URL> /tmp/pathlist`

### Finding Exploitable Vulnerabilities (Exploit-DB)
Searching public repositories for matching software versions to execute RCE.
* **Packet Storm:** [https://packetstormsecurity.com](https://packetstormsecurity.com)
* **Exploit Database:** [https://www.exploit-db.com](https://www.exploit-db.com) (Filter by "Webapps").

### Exploitation via AI (ChatGPT)
* **Prompt:** *"Identify OS and services running on the target 10.10.1.19 and then install and launch the searchsploit to find out the possible exploits..."*
* **AI Output:**
  ```bash
  sudo apt-get update && sudo apt-get install nmap -y && nmap -sV -O 10.10.1.19 -oX nmap_scan.xml && sudo apt-get install exploitdb -y && searchsploit -nmap nmap_scan.xml
  ```

## 8. Session Hijacking

Attackers steal valid session IDs using token prediction, replay, session fixation, sidejacking, and XSS.
* **Burp Suite** ([https://portswigger.net](https://portswigger.net)): Features the **Sequencer** tool to test token randomness and predict future IDs.
* **JHijack** ([https://sourceforge.net](https://sourceforge.net))
* **Ettercap** ([https://www.ettercap-project.org](https://www.ettercap-project.org))
