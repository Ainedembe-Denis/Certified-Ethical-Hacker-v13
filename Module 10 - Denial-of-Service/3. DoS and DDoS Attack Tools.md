## 1. DoS/DDoS Attack Toolkits — EC-Council Primary

*(Source: EC-Council CEH v13)*

### 1.1 ISB (I'm So Bored)
**Source:** https://sourceforge.net

ISB is a software utility used for launching DDoS attacks on target networks.
* **Attack Types:** HTTP, UDP, TCP, and ICMP flood attacks
* **Bonus Feature:** Provides one-click access to commonly used network commands — **WHOIS, netstat, traceroute, ping** — helping attackers discover the target before attacking

### 1.2 UltraDDOS-v2
**Source:** https://sourceforge.net

UltraDDOS-v2 is a DDoS tool for attacking target websites or servers.
* **Interface:** Simple **GUI** — attacker enters target IP address, port number, and number of packets to transmit
* **Usage:** Primarily volumetric — floods the target server with packets and records the flood on the target machine

### 1.3 HOIC (High Orbit Ion Cannon)
**Source:** https://sourceforge.net

HOIC is an advanced DDoS tool designed to cause more damage with fewer users than LOIC.
* **Attack Types:** HTTP GET and POST floods (Layer 7)
* **Key Feature — Booster Scripts:** Add-on scripts that randomise HTTP headers (`User-Agent`, `Referer`) so attack traffic doesn't look automated. Also hits **multiple subpages** of the target simultaneously
* **Scale:** Approximately **50 coordinated users** running HOIC can take down an unprotected small-to-medium website
* **IRC Integration:** Volunteers connect via IRC channel, receive instructions from the attacker, and flood the target

> **💡 CEH Beginner Tip:** HOIC was specifically named in the EC-Council case study where an anonymous hacker advertised it on **Twitter, Facebook, and Google** with malicious download links to recruit volunteers for attacks against targets like PayPal and MasterCard.

### 1.4 LOIC (Low Orbit Ion Cannon)
**Source:** https://sourceforge.net

The most historically famous DoS tool, heavily used by hacktivist group Anonymous.
* **Attack Types:** TCP, UDP, and HTTP floods
* **Interface:** Very simple GUI — enter target URL or IP, select method, click fire
* **Hivemind / IRC Mode:** Connects users' LOIC clients to a central IRC channel where an operator can aim and fire thousands of clients simultaneously — turning individual volunteers into a coordinated botnet
* **Critical Weakness:** LOIC **does not spoof IP addresses**. Every user is visible to the victim and law enforcement — many Anonymous participants were arrested because of this

### 1.5 HULK
**Source:** https://github.com

HULK (HTTP Unbearable Load King) is an application-layer tool designed to bypass caching.
* **Mechanism:** Dynamically generates **unique, randomized HTTP GET requests** for every single packet
* **Impact:** Because every URL is different, caching servers (Varnish, Cloudflare) cannot serve cached pages — every request hits the backend web server and database

### 1.6 Slowloris
**Source:** https://github.com

Slowloris performs Layer-7 DDoS attacks using **perfectly legitimate HTTP traffic**.
* **Method:** Sends partial HTTP requests — the target server opens multiple connections and waits for them to complete indefinitely
* **Result:** The server's maximum concurrent connection pool fills up; additional connections are denied
* **Particularly effective against:** Apache web servers

### 1.7 UFONet
**Source:** https://ufonet.03c8.net

UFONet is an offensive security tool that exploits **Open Redirect vectors** on third-party websites to launch DDoS attacks. It can create "zombies" from web applications vulnerable to open redirect without requiring the attacker to control a traditional botnet.

### 1.8 Packet Flooder Tool
**Source:** https://www.netscantools.com

A network packet generation tool used to send high-volume custom network packets (TCP, UDP, ICMP) to a target. Used in both penetration testing and malicious flooding.

## 2. EC-Council Case Study: HOIC in Action

*(Source: EC-Council CEH v13 — Figure 10.10 DDoS attack scenario)*

This is the explicit case study shown in the CEH v13 curriculum describing how a real DDoS attack using HOIC is organized:

1. **Hacker hosts HOIC** on a web server they own or have compromised
2. **Advertises HOIC** on social media (Twitter, Facebook, Google) with a malicious download link
3. **Volunteers** — users who want to participate — download HOIC from the hacker's link
4. **IRC Channel** — all volunteers connect to the hacker via an IRC channel and await instructions
5. **Target designated** — hacker instructs volunteers to flood a target server (PayPal, MasterCard, PAYBACK)
6. **Flood launched** — volunteers act, causing the target server to become overwhelmed
7. **Result** — target server stops responding to legitimate users

> **Key exam point:** This describes a **crowdsourced DDoS** using real volunteers — not a traditional botnet where victims are unaware they're participating.

## 3. DDoS-for-Hire (Booters/Stressers) — Supplementary

*(Additional knowledge not from EC-Council PDF)*

Modern DDoS is increasingly offered as a **service** to anyone willing to pay. These are known as **Booter** or **Stresser** services:
* Operators run massive botnets (often millions of IoT devices)
* Users access them via simple web dashboards — no technical knowledge required
* Payment in cryptocurrency for anonymity
* Legally marketed as "network stress testing" services
* A typical attack: **~$20 = 1 hour of 50 Gbps attack traffic** against any specified IP

**The Mirai Botnet (Supplementary — key CEH exam topic):**
Mirai caused the **2016 Dyn DNS outage** that took Twitter, Netflix, Reddit, and GitHub offline. Unlike traditional botnets:
* Scans the internet for **open Telnet ports (Port 23)** on IoT devices
* Brute-forces login with a list of **62 hardcoded factory default credentials** (admin/admin, root/12345, etc.)
* Infected device (CCTV cameras, DVRs, home routers) functions normally — owner is unaware
* Device silently participates in massive Tbps volumetric attacks on command
* Peak attack: **1.2 Tbps** against Dyn DNS, disrupting the entire US East Coast
