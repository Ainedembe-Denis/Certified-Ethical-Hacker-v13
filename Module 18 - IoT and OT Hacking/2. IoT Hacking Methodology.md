## 1. Information Gathering

Information gathering is the first step in hacking an IoT device, where attackers extract information such as IP addresses, protocols used (Zigbee, BLE, 5G), open ports, device type, geolocation, and manufacturer details.
*   **Search Engines:** Attackers use search engines like **Shodan**, **Censys**, and **FOFA** to find Internet-connected devices and gather banners and locations.
    *   *Shodan filters:* `webcamxp country:US`, `webcamxp city:paris`, `webcamxp geo:-50.81,201.80`, `net:`, `os:`, `port:`, `before/after:`.
*   **Scanning:** Using tools like **MultiPing** to cycle through IP address ranges and find responding IoT devices in a target network.
*   **FCC ID Search:** Using `fcc.gov` to find device details and certification grants using the Grantee Code and Product ID located on the device's physical label.
*   **Sniffing:** Attackers use **Wireshark** to intercept insecure HTTP/HTTPS traffic and decrypt WEP/WPA Wi-Fi keys of the target network.
    *   `nmap -p 80,81,8080,8081 <Target IP>` (identify HTTP ports)
    *   `ifconfig` (identify interface)
    *   `airmon-ng start wlan0` (put card in monitor mode)
    *   `airodump-ng start wlan0mon` (scan nearby networks)
*   **IoT Packet Sniffing:**
    *   **Cascoda Packet Sniffer:** Captures IEEE 802.15.4 traffic (Thread, KNX-IoT, Zigbee) and analyzes it in Wireshark.
    *   **Suphacap:** A hardware tool used to sniff real-time traffic from Z-Wave networks.

## 2. Vulnerability Scanning

After gathering information, attackers scan for attack surfaces to identify vulnerabilities like weak configurations, hidden exploits, firmware bugs, and poorly encrypted communications.
*   **IoTSeeker:** A tool that scans networks to discover IoT devices (like CCTV cameras) using default, factory-set credentials.
    *   `perl iotScanner.pl <IP address/range of IP’s>`
*   **Genzai:** An IoT security toolkit that detects and scans IoT dashboards (routers, cameras) for default passwords and known vulnerabilities based on signatures.
    *   `./genzai <target_host> -save scan.json`
*   **Nmap:** Used to identify open ports, services, and OS types of IoT devices.
    *   TCP/UDP scan: `nmap -n -Pn -sSU -pT:0-65535,U:0-65535 -v -A -oX <Name><IP>`
    *   IPv6 scan: `nmap -6 -n -Pn -sSU -pT:0-65535,U:0-65535 -v -A -oX <Name><IP>`
*   **Fuzzing Tools:** Tools like **beSTORM** (a smart fuzzer) are used to detect buffer overflow vulnerabilities by automating the delivery of corrupted inputs to the device.
*   **Spectrum Analysis:** Using Software-Defined Radio (SDR) tools like **Gqrx** to analyze radio frequency bands of temperature sensors, smart keys, etc.

## 3. Launch Attacks

Attackers exploit the identified vulnerabilities to launch attacks such as DDoS, rolling-code, jamming, Sybil, and MITM.
*   **Analyzing IoT Traffic:** **ONEKEY** automatically scans the network, displays communication endpoints, and allows attackers to record/replay information to gather sensitive data.
*   **SDR-Based Attacks:** **Universal Radio Hacker (URH)** is used to investigate unknown wireless protocols, reverse engineer them, perform fuzzing, and modulate data back into the system.
*   **Rolling Code Attack:** Attackers use **RFCrack** with SDR hardware (like HackRF One) to capture and replay rolling codes from key fobs (e.g., unlocking cars).
    *   Live replay: `python RFCrack.py -i`
    *   Rolling code: `python RFCrack.py -r -M MOD_2FSK -F 314350000`
    *   Jamming: `python RFCrack.py -j -F 314000000`
*   **Zigbee Hacking:** **Open Sniffer** is a Wireshark-based analyzer that captures IEEE 802.15.4 frames to perform DoS or replay attacks on Zigbee networks.
*   **BlueBorne Attack:** Using **HackRF One** (a hardware SDR) to sniff and exploit Bluetooth protocols to compromise devices.
*   **Replay Attack (HackRF One):**
    *   Record signal: `hackrf_transfer -r connector.raw -f [device frequency]`
    *   Replay signal: `hackrf_transfer -t connector.raw -f [device frequency]`
*   **SDR Attacks (Software):** **GNU Radio** provides tools (`uhd_ft`, `uhd_rx_cfile`, `gr_plot`) to process and generate software radio signals.
*   **Side-Channel Attacks:** **ChipWhisperer** is used for embedded hardware security research to perform side-channel power analysis and glitching attacks to extract cryptographic keys.
*   **Identifying Interfaces (UART, SPI, JTAG, I2C):** Attackers use **BUS Auditor** and the EXPLIoT framework to identify communication buses on a PCB to extract firmware.
    *   `run busauditor.generic.uartscan -v 3.3 -p /dev/ttyACM0 -s 0 -e 1`
    *   `run busauditor.generic.jtagscan -v 3.3 -p /dev/ttyACM0 -s 0 -e 10`
*   **NAND Glitching:** Attackers gain privileged root access during boot by shorting the serial I/O pin of the flash memory chip to ground.
    *   `minicom -D /dev/ttyUSB0 -w -C D-link_startup.txt`
    *   `printenv` and `setenv bootargs` to modify boot parameters.
    *   `nand read` to execute backup loader code.

## 4. Gain Remote Access

Vulnerabilities allow attackers to remotely gain access to the device, turning it into a backdoor into the organization's network.
*   **Telnet Attacks:** Exploiting open telnet ports (discovered via Shodan) and brute-forcing default credentials (root/root, admin/admin) to gain unauthorized access.
*   **Camera Exploitation:** Tools like **CamOver** are used to exploit vulnerabilities in popular camera models (CCTV, GoAhead, Netwave) to disclose administrator passwords.
    *   Exploit single IP: `camover -a <Camera IP Address>`
    *   Exploit via Shodan: `camover -t --shodan <Shodan API Key>`

## 5. Maintain Access

Attackers maintain undetected access by clearing logs, updating firmware with backdoors, and installing rootkits.
*   **Firmware Exploitation:** The **Firmware Mod Kit** is used to extract firmware, make malicious modifications (e.g., to the web UI), rebuild it, and flash it onto the device.
    *   `extract-firmware.sh` (extracts firmware)
    *   `build-firmware.sh` (rebuilds modified firmware)
*   **Firmware Analysis & Reverse Engineering:** Attackers analyze the firmware to find hardcoded passwords, API tokens, and backdoor accounts.
    *   `file *.bin`, `md5sum *.bin`, `strings *.bin`, `hexdump xyz.bin`
    *   **binwalk** is used for reverse engineering and extracting data from the firmware image.
    *   `dd if=xyz.bin bs=1 skip=922460 count=2522318 of=xyz.squashfs`
    *   Mount the filesystem (`mount -t ext2`) and search for sensitive files like `passwd`, `shadow`, `.conf`, and `.pem`.
*   **Dynamic Testing (Emulation):** Emulating the firmware (using **QEMU**) to perform dynamic testing on the device's web interface.
    *   `qemu-mipsel -L <prefix> <binary>`

## 6. IoT Hacking Tools

*   **CatSniffer:** Used to passively monitor IoT traffic and gather information on protocols and data exchanges.
*   **Other Tools:** KillerBee, JTAGULATOR, wiz_exploit, PENIOT, RouterSploit.
