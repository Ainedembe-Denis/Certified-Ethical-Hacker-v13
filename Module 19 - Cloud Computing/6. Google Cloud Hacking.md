## 1. Enumerating GCP Resources (CLI)

Enumerating the Google Cloud Platform (GCP) involves systematically discovering resources, services, configurations, and IAM permissions to find potential vulnerabilities or misconfigurations.

### Organizations, Projects, and Folders
*   **List Organizations:** `gcloud organizations list`
*   **List Folders:** `gcloud resource-manager folders list --organization=<id>`
*   **List Active Projects:** `gcloud projects list`

### Cloud Storage Buckets
*   **List Buckets:** `gsutil ls`
*   **Get Bucket Permissions:** `gsutil iam get gs://<bucket_name>`
*   **List Bucket Contents:** `gsutil ls -r gs://<bucket_name>`

### Service Accounts and Compute Resources
*   **List Service Accounts:** `gcloud iam service-accounts list`
*   **Get Associated Roles:** `gcloud projects get-iam-policy <project-id> --flatten="bindings[].members" --format='table(bindings.role)' --filter="bindings.members:<email>"`
*   **Print Access Token:** `gcloud auth print-access-token --impersonate-service-account=<email>`
*   **List Compute Instances:** `gcloud compute instances list`
*   **Describe Instance:** `gcloud compute instances describe <instance> --zone <zone>`

### Cloud SQL
*   **List SQL Instances:** `gcloud sql instances list`
*   **Enumerate Databases:** `gcloud sql databases list --instance=<instance_name>`

### Enumerating IAM Roles
*   **List Roles:** `gcloud iam roles list [--show-deleted]`
*   **Get IAM Policies:** `gcloud projects get-iam-policy <project id>`

## 2. Automated Enumeration Tools

*   **gcp_service_enum:** A Python script to discover GCP services using a service account key file.
    *   `gcp_enum_services.py -f <key_file> --output-file <out.txt>`
*   **GCP Scanner:** Evaluates the impact of compromised VMs or leaked OAuth2 tokens. Extracts metadata and lists GCE, GCS, GKE, Cloud SQL, BigQuery, and Pub/Sub info.
    *   `python3 scanner.py -o <output_file> -g <gcloud_profile_path>`
*   **cloud_enum:** Multi-cloud OSINT tool to find open GCP buckets, Firebase databases, and App Engine sites.
    *   `cloud_enum.py -k <keyword> --disable-aws --disable-azure`
    *   *Alternative:* Use **GrayhatWarfare** to find publicly accessible buckets.

## 3. Exploitation & Privilege Escalation

### GCP Privilege Escalation Scanner
A Python tool to evaluate IAM policies for misconfigurations that allow privilege escalation.
1.  Enumerate permissions: `python3 enumerate_member_permissions.py --project-id test-<ID>`
2.  Scan for vulnerabilities: `python3 check_for_privesc.py`
3.  Outputs: `privesc_methods.txt` and `setIamPolicy_methods.txt`.

### Escalating Privileges using GCPBucketBrute
Exploiting misconfigured bucket ACLs to escalate privileges to administrator level.
*   The tool checks if "allUsers" or "allAuthenticatedUsers" can read the bucket policy by making a direct request to the `TestIamPermissions` API.
*   If vulnerable, the tool identifies the exact privilege escalation paths available on the storage bucket.

## 4. Maintaining Access & Backdoors

### Creating Backdoors with IAM Roles
Attackers set up persistent access by assigning themselves or controlled service accounts to highly privileged, hidden roles.
1.  **Create New Elevated Role:** `gcloud iam roles create <ROLE_NAME> --project=<ID> --file=role-definition.yaml`
2.  **Bind Role to Service Account:**
    *   `gcloud projects add-iam-policy-binding <PROJECT_ID> --member=serviceAccount:<ACCT>@<ID>.iam.gserviceaccount.com --role=roles/<ROLE_NAME>`

## 5. GCPGoat Scenarios

GCPGoat is a vulnerable-by-design infrastructure for GCP, mimicking real-world cloud flaws based on the OWASP Top 10.
*   **Server-Side Request Forgery (SSRF):** Fetching source code from a cloud function and dumping the database to overtake the admin account.
*   **Misconfigured Storage Bucket Policies:** Exploiting weak policies to gain admin access to cloud buckets.
*   **Lateral Movement:** Extracting credentials from a low-privileged Compute instance (e.g., within a dev bucket) to pivot and access high-privileged Compute instances.
