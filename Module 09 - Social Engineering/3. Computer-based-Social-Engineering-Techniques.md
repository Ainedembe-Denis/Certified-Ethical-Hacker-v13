## 1. Phishing: The Core of Online Deception
**Phishing** is the fraudulent acquisition of sensitive information (passwords, credit cards) by masquerading as a trusted entity in an email or instant message.

### Common Phishing Tools
*   **SET (Social-Engineer Toolkit):** Open-source Python tool for performing advanced attacks against human elements (Web, USB, Email).
*   **ShellPhish:** Phishes credentials for Instagram, Facebook, LinkedIn, etc., while gathering victim IP/Geo data.
*   **Modlishka / Gophish / Zphisher:** Specialized frameworks for automated phishing campaigns.

> **💡 CEH Beginner Tip:** Look for the "Lure." Phishing always starts with a lure—an email that looks like it's from your bank, Microsoft, or even your boss. Always check the **actual** sender address, not just the display name!

## 2. Advanced Phishing Variants
| Type | Description |
| :--- | :--- |
| **Spear Phishing** | Targeted at a specific individual or small group within an organization. |
| **Whaling** | Targets high-profile "Big Fish" (CEOs, CFOs, Politicians). |
| **Pharming** | **DNS Cache Poisoning** or **Host File Modification** to redirect users to fake sites without a lure. |
| **Spimming** | Spam over Instant Messaging (IM). |
| **Clone Phishing** | Creating a near-identical copy of a previously received legitimate email, but replacing links/attachments. |
| **Tabnabbing** | Rewriting an inactive browser tab to a fake login page while the user is distracted. |
| **Consent Phishing** | Tricking users into granting **OAuth permissions** to a malicious app (no password needed). |
| **Search Engine Phishing** | Using **SEO Poisoning** to rank malicious sites high in search results. |

## 3. AI-Powered Social Engineering (Deepfakes)
Attackers now leverage AI (like ChatGPT) to automate and enhance their deception.

### AI Phishing & Impersonation
*   **ChatGPT Automation:** Attackers use prompts to generate perfect emails.
    *   *Prompt Example:* "Pose as a Microsoft support executive. Write a concise mail about a suspicious login and ask for a password reset at [Fake Link]."
*   **Style Mimicking:** Training AI on a target's public posts to replicate their tone.
    *   *Prompt Example:* "Impersonate Sam's sophisticated writing style from these conversations and ask John for urgent money for a family emergency."

### Deepfakes & Voice Cloning
*   **Deepfakes:** Creating fake video/audio using **GANs (Generative Adversarial Networks)**. Requires skills in CNNs, scripting, data preprocessing, and VFX (rotoscoping/motion tracking). Tools: *DeepFaceLab, Vidnoz, Deepfakesweb, Synthesia*.
*   **Voice Cloning:** Replicating a person's tone from an audio sample using neural networks (RNNs). Tools: *VEED.IO, Murf.AI, ElevenLabs, Resemble.AI*.

## 4. Social Media Threats & Catfishing
Social networks are "treasure troves" for reconnaissance.

*   **Angler Phishing:** Creating a fake social media "Help Desk" account to target disgruntled customers complaining publicly.
*   **Catfishing:** Stealing an identity to build fake relationships.
    *   *Warning Signs:* Avoids direct video/calls, maintains the same profile pic for years, has many "friends" of the opposite gender, or requests money for "emergencies."
*   **Facebook Impersonation Steps:**
    1.  Create a fake group (e.g., "Employees of Company XYZ").
    2.  Invite actual employees using a false identity.
    3.  Harvest credentials/personal data from group posts.
    4.  Use details to compromise the physical or digital facility.
*   **Corporate Risks:** Data theft, involuntary leakage by employees, reconnaissance, and malware propagation.

## 5. Identity Theft: Types & Indicators
**Identity Theft** is the illegal use of someone's identification (SSN, Name, Biometrics) for fraud.

### Types of ID Theft:
*   **Child ID Theft:** Desirable because it remains undetected until adulthood.
*   **Financial ID Theft:** Stealing bank/card info to max out credit or take loans.
*   **Criminal ID Theft:** Using a victim's name during an arrest to escape charges.
*   **Medical ID Theft:** Accessing medical products/insurance; can cause dangerous medical record errors.
*   **Driver’s License Theft:** Using a stolen license for traffic violations.
*   **Tax ID Theft:** Filing fraudulent returns to steal refunds.
*   **Insurance ID Theft:** Closely related to medical; targets insurance coverage.
*   **Identity Cloning:** Simply hiding one's identity (e.g., illegal immigrants).
*   **Synthetic Identity Theft:** Combining real SSNs with fake names/addresses.
*   **Social Security Theft:** Defrauding the government for benefits.

### ID Theft Techniques:
*   **Physical Theft:** Stealing wallets, laptops, or backup media.
*   **Skimming:** Using storage devices ("wedges") to steal card numbers.
*   **Pretexting:** "Smooth-talking" to win trust.
*   **Wardriving:** Searching for unsecured Wi-Fi in moving vehicles.
*   **Mail Theft:** Rerouting or stealing mail from mailboxes.
*   **Other:** Dumpster/Shoulder, Phishing, Pharming, Hacking, Keyloggers, Dark Web Trading.

### Warning Signs (Indications):
*   Unexplained withdrawals or unfamiliar charges.
*   Ceasing to receive regular statements (Bank/Utility).
*   Creditors calling about accounts you didn't open.
*   Traffic violations you didn't commit.
*   Multiple tax returns filed in your name.
*   Inexplicable drops in credit score.
*   Notifications about data breaches at companies you use.
*   Sudden changes in medical records or denied insurance claims.

### 📝 Module Summary
Computer-based social engineering has evolved from simple "Nigerian Prince" emails to sophisticated, AI-driven deepfakes and SEO poisoning. As attackers use automation and machine learning to "hack the human," defenders must rely on multi-factor authentication (MFA) and deep skepticism of all unsolicited digital communication.
