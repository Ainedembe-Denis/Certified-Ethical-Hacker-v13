## 1. CEH Ethical Hacking Framework

The EC-Council’s CEH ethical hacking framework defines the step-by-step process of ethical hacking, mirroring the actions of a real attacker.

- **Phase 1: Reconnaissance (Footprinting):** The preparatory phase where the attacker gathers as much information as possible about the target prior to launching an attack (e.g., Whois queries, IP ranges, employee directories). Divided into *Passive* (no direct contact) and *Active* (direct interactions, open ports).
- **Phase 2: Vulnerability Scanning (Scanning & Enumeration):** Using the gathered details to scan the network for specific information (active hosts, open ports) and extracting data like routing tables and user lists (Enumeration). It includes assessing the system's ability to withstand assault.
- **Phase 3: Gaining Access:** Actual hacking occurs here. Exploiting identified vulnerabilities (e.g., password cracking, buffer overflows) to gain OS or application access. Once accessed, the attacker escalates privileges to the administrator level.
- **Phase 4: Maintaining Access:** Retaining ownership of the system using admin/root privileges to upload/download data, install backdoors/malware, and use the system as a launchpad for further attacks.
- **Phase 5: Clearing Tracks:** Erasing evidence of the security compromise (modifying/deleting logs) to remain undetected and retain access.

## 2. Cyber Kill Chain Methodology

Developed by Lockheed Martin, this intelligence-driven framework models the seven stages of a cyberattack. Disrupting any phase breaks the chain and prevents the attack.

1. **Reconnaissance:** Probing for weak points, gathering public info, network blocks, and email addresses.
2. **Weaponization:** Analyzing data to create a tailored, deliverable malicious payload (e.g., phishing email with a remote-access Trojan).
3. **Delivery:** Transmitting the weapon to the target (via email, USB, malicious links).
4. **Exploitation:** Triggering the malicious code to exploit a software/hardware vulnerability on the target system.
5. **Installation:** Downloading and installing more malware/backdoors to maintain extended access and spread the infection.
6. **Command and Control (C2):** Establishing a two-way communication channel between the victim and the attacker's server (often obfuscated via DNS or web traffic).
7. **Actions on Objectives:** Accomplishing the intended goals (data exfiltration, destruction, disruption, or lateral movement).

## 3. Tactics, Techniques, and Procedures (TTPs)

Organizations use TTPs to profile threat actors and stop attacks early.
- **Tactics:** The high-level strategies used to gather information, move laterally, or escalate privileges.
- **Techniques:** The specific tools and methods used at each stage (e.g., encrypting stolen files, using purely human-based social engineering).
- **Procedures:** The exact sequence of actions taken to execute the attack lifecycle.

### Adversary Behavioral Identification
Monitoring network behavior helps detect adversaries:
- **Internal Reconnaissance:** Checking for unusual commands executed in batch scripts or PowerShell.
- **Use of PowerShell:** Used for data exfiltration; monitored via transcript or event logs.
- **Unspecified Proxy Activities:** Adversaries switching between multiple domains pointing to the same host.
- **Use of Command-Line Interface:** Browsing/modifying files via CLI; monitored via anomalous process IDs.
- **HTTP User Agent:** Modifying the user agent field to communicate with C2 servers.
- **Command and Control Server:** Tracking outbound connection anomalies and unwanted open ports.
- **Use of DNS Tunneling:** Obfuscating malicious traffic in DNS requests.
- **Use of Web Shell:** Creating a remote-access shell within a web server.
- **Data Staging:** Collecting and combining sensitive data before exfiltrating it (detected via file integrity monitoring).

## 4. Indicators of Compromise (IoCs)

IoCs are forensic artifacts that indicate a potential intrusion. They are data points (not full intelligence) used to detect and prevent breaches.

**Categories of IoCs:**
- **Email Indicators:** Sender addresses, email subjects, malicious attachments/links.
- **Network Indicators:** URLs, domain names, C2 server IPs.
- **Host-Based Indicators:** Filenames, file hashes, registry keys, DLLs, mutexes.
- **Behavioral Indicators:** Document executing a PowerShell script, anomalous code injection.

**Key Examples of IoCs:**
- Unusual outbound network traffic
- Geographical anomalies
- Multiple login failures
- Large HTML response sizes
- Mismatched port-application traffic
- Suspicious registry/file changes
- Unusual DNS requests
- Web traffic with superhuman behavior

## 5. MITRE ATT&CK Framework

A globally accessible knowledge base of adversary tactics and techniques based on real-world observations. It consists of Enterprise, Mobile, and PRE-ATT&CK matrices.

**Enterprise Tactics (14 categories):**
- Reconnaissance, Resource Development, Initial Access, Execution, Persistence, Privilege Escalation, Defense Evasion, Credential Access, Discovery, Lateral Movement, Collection, Command and Control, Exfiltration, Impact.

## 6. Diamond Model of Intrusion Analysis

A framework for recognizing clusters of events correlated in an intrusion (the "Diamond Event"). It maps the relationships between four core features to trace attacks:

1. **Adversary:** The hacker responsible.
2. **Victim:** The exploited target/environment.
3. **Capability:** The strategies, tools, or malware used.
4. **Infrastructure:** The hardware/software connecting the adversary to the victim.

**Event Meta-Features:** Timestamp, Phase, Result, Direction, Methodology, Resource.

**Extended Diamond Model:**
- **Socio-political:** Describes the relationship/motivation between adversary and victim (e.g., financial gain, hacktivism).
- **Technology:** Describes how technology enables communication/operation between infrastructure and capability.
