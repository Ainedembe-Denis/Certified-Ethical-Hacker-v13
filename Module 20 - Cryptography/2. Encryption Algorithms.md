## 1. Symmetric Encryption Algorithms

| Algorithm | Cipher Type | Key Size (bits) | Block Size (bits) | Application Areas |
| :--- | :--- | :--- | :--- | :--- |
| **DES** | Block | 56 bits | 64 bits | Legacy systems, early encryption |
| **3DES** | Block | 112, 168 bits | 64 bits | Financial services, payment systems |
| **AES** | Block | 128, 192, 256 bits | 128 bits | Secure communications, storage, government |
| **RC4** | Stream | 40 to 2048 (variable) | N/A | HTTPS, WEP/WPA, streaming |
| **RC5** | Block | 0 to 2040 (variable) | 32, 64, 128 | Cryptographic libraries |
| **RC6** | Block | 128, 192, 256 bits | 128 bits | AES competition finalist |
| **Blowfish** | Block | 32 to 448 (variable) | 64 bits | Replacement for DES, secure storage |
| **Twofish** | Block | 128, 192, 256 bits | 128 bits | File and disk encryption |
| **IDEA** | Block | 128 bits | 64 bits | Secure email (PGP) |
| **Threefish** | Block | 256, 512, 1024 bits | 256, 512, 1024 | Disk encryption (Skein hash function) |
| **Serpent** | Block | 128, 192, 256 bits | 128 bits | High-security applications |
| **Camellia** | Block | 128, 192, 256 bits | 128 bits | Japanese encryption standard |
| **TEA** | Block | 128 bits | 64 bits | Lightweight encryption, embedded systems |
| **CAST-128** | Block | 40 to 128 bits | 64 bits | GPG and PGP default cipher |

### Deep Dive: Symmetric Algorithms
*   **Data Encryption Standard (DES):** Uses a 64-bit secret key (56 bits randomly generated, 8 for error detection). Operates on 64-bit blocks. Now obsolete due to processing speed exposing it to brute-force.
*   **Triple DES (3DES):** Applies the DES algorithm three times with a key bundle (K1, K2, K3). Process: *Encrypt with K1 -> Decrypt with K2 -> Encrypt with K3*.
*   **Advanced Encryption Standard (AES):** NIST specification that replaced DES. It is an iterated block cipher operating on 128-bit blocks with 128, 192, or 256-bit keys. Uses `AddRoundKey`, `SubBytes`, `ShiftRows`, and `MixColumns` operations.
*   **RC4, RC5, RC6:** Developed by Ron Rivest. RC4 is a fast stream cipher. RC5 is a parameterized block cipher (variable block/key size/rounds) using integer addition, XOR, and variable rotation. RC6 derives from RC5 but uses integer multiplication and four 4-bit working registers.
*   **Blowfish:** 16-round Feistel cipher working on 64-bit blocks. Splits the key into an 18-entry P-array and four 256-entry S-boxes.
*   **Twofish / Threefish / Serpent:** Twofish and Serpent were AES finalists. Threefish is tweakable and avoids S-boxes to prevent cache timing attacks. Serpent uses 32 rounds of substitution/permutation but is slower than AES (Rijndael).
*   **TEA (Tiny Encryption Algorithm):** Extremely simple to implement. Uses a 128-bit key on 64-bit blocks with a constant (delta = 232/golden ratio) and employs addition/subtraction instead of XOR.
*   **CAST-128 / CAST-256:** Uses a 12-or 16-round Feistel network. CAST-128 is the default for GPG and PGP.
*   **GOST Block Cipher (Magma):** A 32-round Feistel network with 64-bit blocks and a 256-bit key. `Kuznyechik` is its 128-bit block extension.

## 2. Asymmetric Encryption Algorithms

| Algorithm | Key Size (bits) | Application Areas |
| :--- | :--- | :--- |
| **RSA** | 1024 to 15360 | Encryption, digital signatures, key exchange |
| **DSA** | Variable | Digital signatures (FIPS 186) |
| **Diffie-Hellman** | Variable | Key exchange, secure communication (TLS) |
| **ECC** | 160 to 521 | Encryption, digital signatures, key exchange |
| **YAK** | Variable | Authenticated Key Exchange (AKE) |

### Deep Dive: Asymmetric Algorithms
*   **Digital Signature Algorithm (DSA):** FIPS standard for digital signatures. Uses a pair of private/public keys and mathematical parameters (prime numbers `p`, `q`, generator `g`) to securely sign (with private key) and verify (with public key) data.
*   **Rivest Shamir Adleman (RSA):** The de-facto encryption standard. Relies on the computational difficulty of factoring large prime numbers. 
    *   *Mathematical Basis:* Select two large primes `P` and `Q`. Find Modulus `c = P * Q`. Public key is `(PQ, E)`, private key is `D`.
    *   Encryption: `C = (T^E) mod PQ` (C=Ciphertext, T=Plaintext).
    *   Decryption: `T = (C^D) mod PQ`.
*   **Diffie-Hellman:** Protocol enabling two parties to establish a shared secret key (`k`) over an insecure channel. Uses a prime `p` and generator `g`. Alice computes `g^a mod p`, Bob computes `g^b mod p`. They exchange public values to derive the shared secret. Vulnerable to MITM unless authenticated.
*   **Elliptic Curve Cryptography (ECC):** Uses algebraic structures of elliptic curves over finite fields. It provides the same level of security as RSA but with significantly smaller key sizes (e.g., a 256-bit ECC key offers the same security as a 3072-bit RSA key), making it faster and ideal for mobile devices.
*   **YAK:** A public-key-based Authenticated Key Exchange (AKE) protocol. A variant of HMQV using zero-knowledge proofs (ZKP) to prove knowledge of ephemeral secret keys.

## 3. Message Digest (One-way Hash) Functions

Hash functions calculate a unique, fixed-size bit string (fingerprint/digest) from an arbitrary block of data. They are "one-way" because they cannot be reversed to reveal the plaintext. They are primarily used for integrity checking and digital signatures.

| Algorithm | Output Size | Block Size | Operations |
| :--- | :--- | :--- | :--- |
| **MD5** | 128 bits | 512 bits | Logical (AND, OR, XOR) |
| **MD6** | 224, 256, 384, 512 | 512 bits | Logical (AND, OR, XOR) |
| **SHA-1** | 160 bits | 512 bits | Bitwise logical |
| **SHA-2** | 224, 256, 384, 512 | 512, 1024 | Logical (AND, OR, XOR) |
| **SHA-3** | 224, 256, 384, 512 | 1600 bits | Sponge construction |
| **RIPEMD-160** | 160 bits | 512 bits | Logical (AND, OR, XOR) |

### Hash Function Details
*   **MD5:** Outputs a 128-bit digest. It is mathematically vulnerable to collision attacks (where two different inputs yield the same hash) and is considered obsolete for high-security applications.
*   **MD6:** Uses a Merkle-tree-like structure allowing large-scale parallel computation. Resistant to differential cryptanalysis.
*   **SHA (Secure Hashing Algorithm):** Developed by NIST. `SHA-1` (160-bit) is obsolete. `SHA-2` (256/512-bit) is the current standard. `SHA-3` utilizes a "sponge construction" where data is XORed into the state and invertibly permuted.
*   **RIPEMD-160:** A 160-bit hash algorithm replacing the original RIPEMD (which had collision issues). The compression function runs 80 stages (5 blocks x 16 times) twice.
*   **HMAC (Hash-based Message Authentication Code):** Uses a cryptographic key along with a hash function (like SHA-1 or MD5). The key is processed to produce an inner and outer key, and the hash function is executed twice to prevent length-extension attacks.
*   **GOST Hash:** Russian national standard producing a 256-bit output.

### Calculators
*   **HashMyFiles:** A GUI utility to calculate MD5 and SHA1 hashes of files.
*   **MD5 Calculator (Bullzip):** Used for verifying the integrity of large files via MD5 checksums.

## 4. Multilayer Hashing

Multilayer (nested or recursive) hashing involves applying a hash function multiple times to the input or the output of a previous hash operation. This adds complexity and thwarts brute-force attacks.
*   **Example Tool:** **CyberChef** (https://gchq.github.io/CyberChef)
*   **Process:** Upload a file -> Drag and drop `MD5` -> Drag and drop `SHA1` below it -> The file is hashed via MD5, and that hash is fed as input into SHA1 to produce the final multilayered hash output.

## 5. Cryptography Toolkits

*   **BCTextEncoder:** Simplifies the encoding/decoding of text data. Compresses, encrypts, and converts plaintext into text format using public-key and password-based encryption.
*   **OpenSSL:** An open-source command-line toolkit implementing SSL/TLS. Used for generating private/public keys, X.509 certificates, CSRs, and CRLs.
    *   `openssl enc -ciphers` (lists supported ciphers like aes-128-cbc, aria-256, blowfish).
*   **Other Toolkits:** wolfSSL, AES Crypto Toolkit, Libsodium, Crypto++, PyCryptodome.
