## 1. Apple iOS Architecture

iOS acts as an intermediary between apps and underlying hardware. The architecture consists of 5 layers:
1.  **Cocoa Application:** Key frameworks for UI and basic infrastructure (multitasking, push notifications). Uses the **AppKit** framework.
2.  **Media:** Graphics, audio, and video technologies (Core Animation, Core Audio, OpenGL).
3.  **Core Services:** Fundamental system services (Core Foundation, Address Book, Social, Security, WebKit).
4.  **Core OS:** Low-level features dependent on the kernel (Accelerate, Disk Arbitration, System Configuration).
5.  **Kernel and Device Drivers:** Lowest layer; includes the kernel, drivers, BSD, file systems, networking (Mach).

## 2. Jailbreaking iOS

Jailbreaking installs modified kernel patches allowing third-party, unsigned apps (side loading) and providing root access by removing sandbox restrictions.
*   **Risks:** Voids warranty, poor performance, malware infection, device bricking.

### Types of Jailbreaking
1.  **Userland Exploit:** Loophole in system applications. Grants user-level access but *not* iboot-level. Cannot cause a recovery mode loop. Patched via firmware updates.
2.  **iBoot Exploit:** Takes advantage of third bootloader (iBoot) to delink code-signing. Can be semi-tethered. Grants user and iboot-level access. Patched via firmware.
3.  **Bootrom Exploit:** Loophole in SecureROM (first bootloader) to disable signature checks. Loads patched NOR firmware. **Cannot be patched by firmware updates**; requires a hardware update.

### Jailbreaking Techniques
*   **Untethered:** Device boots completely with a patched kernel without needing a computer after each reboot.
*   **Semi-tethered:** Device boots normally without a patched kernel. Requires running a jailbreak app/tool on the device to use jailbroken addons.
*   **Tethered:** Device gets stuck in a partially started state upon reboot. Must be connected to a computer to "boot tethered" every time it is turned on.
*   **Semi-untethered:** Similar to semi-tethered. Kernel is patched via an app installed on the device after reboot.

### Jailbreaking iOS Using Hexxa Plus
Hexxa Plus (https://hexxaplus.com) is a repo extractor to install tweaks/apps without untethered/semi-untethered jailbreaks.
1.  Go to Xookz App Store -> Hexxa (Full).
2.  Install configuration profile on iPhone.
3.  Navigate to Settings -> Downloaded profile -> Install.
4.  Open Hexxa Plus Repo Extractor -> Get Repos.
5.  Copy URL -> Extract Repo -> Paste URL.

### Jailbreaking Tools
*   **Redensa** (https://pangu8.com): Comes with iTerminal; installs IPAs easily.
*   **Other Tools:** checkra1n, palera1n, Zeon, Sileo, Cydia.

## 3. Analyzing & Manipulating iOS Applications

### Manipulating iOS Application Using Cycript
**Cycript** (http://www.cycript.org) is a runtime manipulation tool/JS interpreter that understands Objective-C, Objective-C++, and JS.
*   Used for **Method Swizzling** (monkey patching): swapping existing functionality at runtime. Used for logging, JS injections, and auth bypass.
    1.  Identify method selector reference.
    2.  Create customized method.
    3.  Run app.
    4.  Swap functionality in Objective-C runtime.

### Extracting Secrets Using Keychain Dumper
iOS stores secrets (passwords, certificates) in the encrypted **keychain**.
*   **Keychain Dumper** (https://github.com/ptoomey3/Keychain-Dumper): Uses a self-signed certificate with wildcard entitlements to dump secrets. (Note: Recent iOS requires explicit entitlements).

### Analyzing iOS Application Using `objection`
**objection** (https://github.com/sensepost/objection) performs method hooking, patching, SSL pinning bypass, and keychain dumping using Frida.
*   Run and attach: `objection --gadget <AppName> explore`
*   Monitor methods of a class: `ios hooking watch class <Class_Name>`
*   Hook specific method: `ios hooking watch method "-[Class_Name Method_Name]"`
*   Change boolean return value: `ios hooking set return_value "-[Class_Name iFunction_Name:]" true/false`
*   Bypass SSL Pinning: `ios sslpinning disable`
*   Bypass Jailbreak Detection: `ios jailbreak disable`

### iOS Trustjacking
Exploits the "iTunes Wi-Fi Sync" feature. 
*   **Process:** Victim connects to an infected computer and clicks "Trust This Computer". The attacker can monitor screen ops, read SMS, and backup data over Wi-Fi even after physical disconnection.

### Post-exploitation Using SeaShell Framework
**SeaShell** (https://github.com/EntySec/SeaShell) exploits the CoreTrust vulnerability (via TrollStore) to bypass signature checks and execute unauthorized software (Pwny payload via TCP listener).
1.  Launch framework: `seashell`
2.  Patch IPA: `ipa patch Instagram.ipa`
3.  Start listener: `listener on <IP address> <Port no>`
4.  Interact: `devices -i <id>`
5.  Extract history: `safari_history` (Parses `/var/mobile/Library/Safari/`)

## 4. Analyzing iOS Devices

### Accessing Device Shell
Requires jailbroken device + OpenSSH.
1.  Connect to Wi-Fi.
2.  SSH: `ssh root@<device_ip_address>` (Default password: `alpine`)
*Via USB:* Use `usbmuxd` / `iproxy` and `ssh -p 2222 root@localhost`. (Note: Fails after 1 hour due to USB Restricted Mode).

### Listing Installed Apps
*   Frida: `frida-ps -Uai` (Note identifier and PID).

### Network Sniffing
1.  Connect via USB.
2.  Create virtual interface: `rvictl -s <UDID of the iOS device>`
3.  Start Wireshark on `rvi0`.
4.  Filter: `ip.addr == 192.168.2.4 && http`

### Obtain Open Connections
*   All processes: `lsof -i`
*   Specific process: `lsof -i -a -p <pid>`

### Process Exploration
Use `r2frida` to get memory maps and loaded libraries.
*   Start session: `r2 frida://usb//iGoat-Swift`
*   Get memory maps: `:dm`
*   List libraries: `:il`
*   In-memory search (hide progress): `\e~search`

## 5. iOS Malware & Hacking Tools

### iOS Malware
*   **GoldPickaxe:** Trojan that tricks victims into scanning their faces/IDs via fake MDM profiles. Used to bypass facial recognition and drain bank accounts.
*   **Other Malware:** SpectralBlur, Mercenary Spyware, LightSpy, KingsPawn, Pegasus.

### iOS Hacking Tools
*   **Spyzie** (https://spyzie.io): Remote invisible hacking of SMS, call logs, GPS without jailbreaking.
*   **Elcomsoft Phone Breaker** (https://www.elcomsoft.com): GPU accelerated decryption of iCloud backups, keychains, and tokens over-the-air.
*   **Other Tools:** Enzyme, Network Analyzer, iOS Binary Security Analyzer, iWepPRO, Frida.
