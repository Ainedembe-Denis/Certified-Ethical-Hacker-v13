## 📌 Introduction to Maintaining Access
After successfully gaining access and escalating privileges on a target system, an attacker's next critical goal is to **maintain that access**. This ensures they don't lose their foothold if the user reboots the system or changes their password. 

Maintaining access turns the compromised system into a permanent bridgehead. From here, attackers can further exploit the system itself (to steal data) or use it as a launchpad to move laterally and attack other systems within the same network. To achieve this, attackers remotely execute malicious applications such as keyloggers and spyware, hiding their presence using techniques like rootkits, steganography, or NTFS data streams.

---

## 🚀 Executing Applications (Owning the System)
Once an attacker acquires administrative privileges through privilege escalation, they reach a stage often referred to as **"owning" the system**. At this point, the attacker has the power to execute arbitrary code and install malicious applications. 

**Why Execute Applications?**
Executing these applications allows the attacker to automate data theft, maintain absolute control without needing to exploit the initial vulnerability again, and gather deep intelligence on the target.

### Common Malicious Programs Executed:
| Type | Explanation |
| :--- | :--- |
| **Backdoors** | A hidden entry point into a system that bypasses normal authentication. Once installed, an attacker can return to the system at any time without having to re-exploit it. |
| **Crackers** | Specialized software scripts designed specifically to brute-force or decrypt passwords and codes found on the compromised system. |
| **Keyloggers** | Hardware or software that covertly records every keystroke. They are highly dangerous because they capture passwords as they are typed—*before* they are encrypted by the system. |
| **Spyware** | Stealth surveillance software that captures screenshots, activates webcams/microphones, and actively sends this aggregated intelligence back to the attacker. |

## 💻 Remote Code Execution Techniques
To maintain access and spread across a network, attackers employ various Remote Code Execution (RCE) techniques. These tactics are designed to run malicious instructions on remote machines either silently in the background or by tricking the user.

### 1. Exploitation for Client Execution
This technique relies heavily on insecure coding practices found in client-side software. Instead of attacking a network service directly, the attacker targets the applications the user interacts with daily.
- **Web-Browser-Based:** Attackers compromise websites (drive-by compromise) or send spear-phishing links. When the victim simply browses the page, the browser's vulnerabilities are exploited to execute code silently without requiring the user to download anything voluntarily.
- **Office-Applications-Based:** Attackers email malicious Microsoft Office documents. To execute the code, the attacker relies on the user opening the file, which triggers macro scripts or exploits within the Office application.
- **Third-Party Applications-Based:** Common auxiliary software like Adobe Reader or Flash is targeted because users often forget to keep them updated, leaving known vulnerabilities exposed.

### 2. Service Execution
System services are foundational background programs that keep the OS running. By communicating directly with the Windows Service Control Manager, attackers can modify an existing legitimate service or create a new hidden one. This ensures their malicious code runs automatically every time the computer boots, running with the highest system privileges (SYSTEM level).

### 3. Windows Management Instrumentation (WMI)
WMI is a legitimate, powerful Windows administration framework used to manage system data and operations remotely. 
- **The Threat:** Attackers love WMI because it allows them to interact with systems, gather data, and execute code using built-in, trusted Windows tools—a technique known as "Living off the Land" (LotL). Since WMI is supposed to be there, its malicious use is very hard for antivirus tools to detect.
- **Protocols Used:** Distributed Component Object Model (DCOM) via port `135`, Windows Remote Management (WinRM) via HTTP port `5985` and HTTPS port `5986`.

### 4. Windows Remote Management (WinRM)
WinRM is the Microsoft implementation of WS-Management Protocol, designed to allow administrators to run executables and modify the registry remotely. Attackers abuse the built-in `winrm` command to seamlessly execute payloads on remote systems as they move laterally through a corporate network.

## ⌨️ Keyloggers
Keyloggers are insidious tools (hardware or software) that secretly record every keystroke entered by a user. They are often deployed silently via email attachments or drive-by downloads. 

**Why are they so effective?** Data transmitted over the internet is usually encrypted (like HTTPS for banking). However, a keylogger tracks the keystrokes *at the hardware or OS level* before the encryption ever takes place. This gives the attacker access to plain-text passphrases and highly confidential information.

### Capabilities of a Keylogger
Beyond just recording keys, a modern keylogger acts as a comprehensive surveillance tool. It can:
- Capture screenshots at regular intervals to map exactly what the user is looking at.
- Track application usage by recording Window titles and the names of launched programs.
- Unmask hidden passwords (data displayed as asterisks `***`).
- Make unauthorized copies of outgoing and incoming emails or chat logs.
- Sniff the clipboard (copy/paste data).
- Implement persistence mechanisms so the logger survives reboots and evades antivirus scans.

---

### 🗂️ Types of Keystroke Loggers

#### 1. Hardware Keystroke Loggers
These are physical devices that sit directly between the keyboard and the computer's port. 
- **The Advantage:** Because they operate entirely at the hardware level, they process data before it reaches the operating system. This makes them 100% invisible to OS-based anti-keylogger or antivirus software.
- **The Catch:** They require physical access to install and can be visually discovered by a vigilant user.

**Sub-types:**
- **PC/BIOS Embedded:** Deep tampering where the BIOS firmware itself is modified to capture keystrokes.
- **Keylogger Keyboard:** A standard-looking keyboard that secretly has a logging circuit built into its internal wiring.
- **External Keylogger:** Small adapter devices.
  - **PS/2 and USB:** Small plugs inserted between the keyboard cable and PC.
  - **Acoustic/CAM:** Analyzes the unique electromagnetic sound waves of keys being pressed, or uses a micro-camera.
  - **Wi-Fi / Bluetooth:** Logs keys locally but has an antenna to transmit the plain-text logs to an attacker sitting nearby or over the internet.

#### 2. Software Keystroke Loggers
These are malicious applications installed remotely via network exploits or phishing. They are not limited by physical memory like hardware loggers and can transmit massive log files to the attacker via email.

**Sub-types:**
- **Application Keylogger:** Targets specific apps, capturing text fields within browsers or chat clients specifically.
- **Kernel/Rootkit/Device Driver Keylogger:** Replaces the core I/O keyboard driver in the Windows kernel. Because it operates at the deepest system layer (Ring 0), standard user-mode antivirus programs cannot see it.
- **Hypervisor-Based Keylogger:** Runs the entire OS inside a malicious virtual machine layer, intercepting all hardware calls.
- **Form-Grabbing-Based Keylogger:** Sniffs web browsers specifically for the "submit event" (clicking a login button) to steal form data before HTTPS encrypts it.
- **JavaScript-Based Keylogger:** Malicious scripts injected into vulnerable websites (via Cross-Site Scripting). It listens for web page events like `onKeyUp()` to steal passwords directly from the browser window.
- **Memory-Injection-Based Keylogger:** Re-writes memory tables of running browser processes to sniff inputs. This method is also used to bypass User Account Control (UAC) prompts.

---

### 💻 Remote Keylogger Attack Using Metasploit
Attackers who have successfully exploited a machine often use the Metasploit Framework to quickly deploy a keylogger to harvest complex passwords they couldn't crack otherwise.

**Step-by-Step with the Meterpreter Shell:**
1. **Find a Stable Process:** `ps` (Lists running processes).
2. **Hide the Hook:** `migrate <PID>` (Moves the attacker's active session into a stable, hidden process like `explorer.exe` so the session doesn't die).
3. **Start Logging:** `keyscan_start` (Initiates the hook into the keyboard driver).
4. **Retrieve Data:** `keyscan_dump` (Dumps the captured keystrokes live onto the attacker's console).
5. **Clean Up:** `keyscan_stop` (Stops the process).

*Note: Metasploit also includes the `lockout_keylogger` exploit modules to automate this entirely.*

## 🕵️‍♂️ Spyware
Spyware is a broader category of stealth monitoring software. While a keylogger focuses strictly on keyboard inputs, spyware acts like a comprehensive surveillance camera aimed at your entire digital life. 

**How it Propagates:**
- **Piggybacking:** Users install a free game or utility, unaware that spyware is secretly bundled inside the installer.
- **Drive-by Downloading:** Merely visiting a compromised website can trigger an exploit that forcefully installs the spyware in the background.
- **Masquerading:** Ironically, spyware often disguises itself as anti-spyware pop-ups on the web ("Your PC is infected! Click here to clean it!").

### What Does Spyware Do?
Spyware seeks complete intelligence gathering and system manipulation. Beyond just recording data, it actively alters the environment:
- Steals banking credentials, social media logins, and corporate emails.
- Alters browser default settings, homepage, and creates annoying pop-up environments.
- Desynchronizes network settings, deliberately disabling firewalls to ensure it has a free path to send logs back to the attacker's Command and Control (C2) servers.
- Turns on microphones and webcams to physically surveil the victim's surroundings.

## 🛡️ Defensive Measures
Defending against persistent applications requires a "Defense in Depth" approach—combining careful user habits with aggressive technical countermeasures.

### 🚫 Defending Against Keyloggers
**General & Pre-emptive Measures:**
- **Antivirus & Anti-Spyware:** Install professional AV/Anti-Spyware and keep signatures up to date. Scan files thoroughly before installation to proactively detect keyloggers (use a registry editor or process explorer).
- **Firewalls & IDS:** Install professional firewall software and a Host-based Intrusion Detection System (HIDS) to monitor the system and disable the installation of keyloggers.
- **Application Whitelisting:** Enable it to block the downloading or installing of unwanted software.
- **System Hardening:** Regularly update and patch system software and OS. Reconfigure the device occasionally to avoid malware stacking on default factory settings. Keep track of browser extensions running in the background and discard untrusted ones.

**Input Security (Evading the Keyboard):**
- **Alternative Inputs:** Use the Windows on-screen keyboard accessibility utility with a mouse to enter confidential info, or utilize licensed Voice-to-Text (V2T) conversion tools. Upgrade to touchscreen-based laptops where physical keylogging is virtually impossible.
- **Password Managers:** Use automatic form-filling password managers or third-party password storage vaults to securely organize credentials and remove the need to physically type anything.
- **Keystroke Interference:** Use keystroke interference software that deliberately inserts randomized characters into every keystroke.

**Network & Access Controls:**
- **Secure Authentication:** Use One-Time Passwords (OTP) or Multi-Factor Authentication (MFA). Avoid similar or identical passwords across personal area network (PAN) devices (smartphones, laptops) and frequently change account passwords to make attacker tasks more complex.
- **Safe Browsing & Connectivity:** Use pop-up blockers, delete phishing emails, and never click links in unsolicited/dubious emails. Avoid using public Wi-Fi for crucial activities like financial transactions. Use a VPN to enable an additional layer of protection through encryption.
- **Encryption:** Employ full disk encryption and secure communication channels (HTTPS, SSL). Segment the network into separate zones to limit lateral movement of keyloggers.

**Detection & Response:**
- **System Monitoring:** Use software that frequently scans and monitors changes in the system/network. Employ Endpoint Detection and Response (EDR) solutions for continuous monitoring. Use process-monitoring tools to detect suspicious processes. Deploy File Integrity Monitoring (FIM) tools like SolarWinds SEM or OSSEC.
- **Memory Forensics:** Leverage memory mapping, memory dumping, and strings extraction to analyze system memory for active keylogger traces.
- **User Vigilance:** Do not ignore suspicious activities like lags in character display, slow image loading, or repeated browser crashes.
- **Data Protection:** Maintain an isolated, secured backup of files on a separate hard drive. Secure data with a proper cyber coverage (insurance) policy to limit disastrous impacts.

#### Hardware Keylogger Countermeasures
Because software defenses can't see physical keyboard intercepts, physical IT security is required.
- **Physical Security:** Physically lock down sensitive computer systems. Periodically check keyboard cables/interfaces and video monitor cables for extra attached connectors (or hardware hidden inside PS2 games). Set up video surveillance around the computer desk.
- **USB Controls:** Disable USB ports or set up advanced BIOS authentication mechanisms to enable USB ports. Use physical security measures like USB port locks or covers.
- **Hardware/Device Strategies:** Ensure device whitelisting to only allow trusted keyboards. Use cryptographic encryption between the keyboard and its driver. Use stylus pens, light pens, or mouse gestures and convert graphics to text instead of using conventional keyboards.
- **Detection Devices:** Employ hardware-based signal monitoring devices (oscilloscope or multimeter) to test keyboard cables for unexpected signals or voltage fluctuations indicating an interceptor.
- **Specialized Anti-Keyloggers:** Use anti-keyloggers specifically designed to detect hardware keyloggers, such as the KeyGrabber Forensic Keylogger.

### 🚫 Defending Against Spyware
Defending against persistent applications requires a "Defense in Depth" approach—combining careful user habits with aggressive technical countermeasures.

**User Habits & Safe Browsing:**
- **Avoid Public Systems:** Never store personal or financial information on computer systems you do not completely control (e.g., computers in an Internet café).
- **Safe Downloading:** Exercise extreme caution with freeware, shareware, P2P swapping software, free music files, emoticons, and screensavers. Ensure software is from a trusted site and always thoroughly scan it before installing.
- **Read Disclosures:** Carefully read End-User License Agreements (EULA), security warnings, and Privacy Statements—spyware components are secretly bundled and sometimes buried in the fine print.
- **App Permissions:** Verify an application's legitimacy before granting access to sensitive hardware like the location service, camera, or microphone.
- **Beware of Phishing & Pop-Ups:** Avoid opening suspicious file attachments or spam links. Never click on pop-up windows claiming "your computer may be infected" or "make your PC run faster."
- **Use Bookmarks:** Bookmark frequently visited websites for safe browsing to ensure you don't mistype a URL and hit a drive-by download site.

**System & Network Hardening:**
- **Least Privilege:** Avoid operating in administrative mode unless necessary. Excessive use might allow malicious programs to run with complete system control.
- **Browser Security:** Adjust Internet browser security settings to either High or Medium (never excessively low). Use privacy settings to limit tracking cookies, and install anti-tracking-based extensions for private browsing.
- **Firewalls:** Enable robust firewalls with strict **outbound protection** rules to ensure spyware cannot successfully phone home.
- **Avoid Untrusted Connections:** Never connect to unknown/rogue Wi-Fi networks or devices.

**Monitoring & OS Protections:**
- **Patch Management:** Keep the Operating System (periodically perform Windows Updates) and installed software thoroughly up-to-date. Regularly update virus definition files.
- **System Auditing:** Regularly check the **Task Manager** and **MS Configuration Manager (`msconfig`)** reports to spot irregular background processes.
- **Memory Protection Mechanisms:** Utilize memory protection mechanisms like **Data Execution Prevention (DEP)** and **Address Space Layout Randomization (ASLR)** to prevent malicious code from actively exploiting memory vulnerabilities.
- **Dedicated Anti-Spyware:** Install anti-spyware software as the first line of defense to prevent installation and perform periodic sweeping scans across the drive.
