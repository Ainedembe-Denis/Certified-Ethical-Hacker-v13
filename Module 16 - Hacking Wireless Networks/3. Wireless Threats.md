## 1. Access Control Attacks

Wireless access-control attacks aim to penetrate a network by evading WLAN access-control measures such as AP MAC filters and Wi-Fi port access controls.

| Attack Type | Description |
| :--- | :--- |
| **MAC Spoofing** | Attackers reconfigure their MAC address to appear as an authorized AP to a host using tools like SMAC. |
| **AP Misconfiguration** | Improperly configured APs do not trigger IDS alerts. Attackers exploit default SSIDs, weak passwords used as SSIDs, and configuration errors. |
| **Ad Hoc Associations** | Wi-Fi clients communicate directly without an AP. This mode is inherently insecure (no strong auth/encryption). Attackers connect in ad hoc mode to compromise clients and use them to penetrate the wired LAN. |
| **Promiscuous Client** | Attackers place an AP near the target network with a common SSID but a stronger signal to lure the client. The promiscuous client allows the attacker to transmit target traffic through a fake AP (similar to Evil Twin). |
| **Client Mis-association** | Clients accidentally or intentionally connect to an AP outside the legitimate network. Attackers set up a rogue AP outside the perimeter, advertise a spoofed SSID, and use it to bypass enterprise policies and launch MITM/EAP dictionary attacks. |
| **Unauthorized Association** | Takes two forms: **Accidental** (connecting to an overlapping neighbor network) and **Malicious** (attackers create "soft APs" on laptops to trick users into connecting; used to steal passwords or plant Trojans). |

## 2. Integrity Attacks

Integrity attacks involve changing or altering data during transmission. Attackers send forged control, management, or data frames.

| Type of Attack | Description | Method / Tools |
| :--- | :--- | :--- |
| **Data-Frame Injection** | Constructing and sending forged 802.11 frames. | Airpwn-ng, Wperf |
| **WEP Injection** | Constructing and sending forged WEP encryption keys. | WEP cracking + injection tools |
| **Bit-Flipping Attacks** | Capturing the frame, flipping random bits in the payload, modifying the ICV, and sending it. | N/A |
| **Extensible AP Replay** | Capturing 802.1X EAP protocols (Identity, Success, Failure) for later replay. | Wireless capture + injection tools |
| **Data Replay** | Capturing 802.11 data frames for later (modified) replay. | Capture + injection tools |
| **IV Replay Attacks** | Deriving the keystream by sending a plaintext message. | N/A |
| **RADIUS Replay** | Capturing RADIUS Access-Accept or Reject messages for later replay. | Ethernet capture + injection tools |
| **Wireless Viruses** | Viruses provide attackers a simple method to compromise APs. | N/A |

## 3. Confidentiality Attacks

These attacks attempt to intercept confidential information sent over the network. If data is encrypted, the attacker attempts to break the encryption.

| Type of Attack | Description | Method / Tools |
| :--- | :--- | :--- |
| **Eavesdropping** | Capturing/decoding unprotected traffic to obtain sensitive info. | Wireshark, Ettercap, Kismet |
| **Traffic Analysis** | Inferring info from observing external traffic characteristics. | Wireshark, Ettercap, Snort |
| **Cracking WEP Key** | Recovering WEP key using brute-force or FMS cryptanalysis. | Aircrack-ng, WEPCrack |
| **Evil Twin AP** | Posing as an authorized AP by beaconing the WLAN's SSID. | Hostapd, EvilTwinFramework, Wifiphisher |
| **Honeypot AP** | Setting an AP's SSID to match a legitimate AP. | Manipulating SSID |
| **Session Hijacking** | Manipulating the network so the attacker appears as the desired destination. | Manipulating |
| **Masquerading** | Pretending to be an authorized user. | Stealing IDs/passwords |
| **MITM Attack** | Running conventional MITM tools on an Evil Twin AP to intercept TCP sessions or SSL/SSH tunnels. | dsniff, Ettercap, aLTEr attack |

## 4. Availability Attacks

Availability attacks obstruct the delivery of wireless services by crippling WLAN resources or denying access.

| Type of Attack | Description | Method / Tools |
| :--- | :--- | :--- |
| **Access Point Theft** | Physically removing an AP from its installed location. | Stealth / Speed |
| **Disassociation Attacks**| Destroying connectivity between AP and client. | Connectivity destruction |
| **EAP-Failure** | Observing a valid 802.1X exchange and sending a forged EAP-Failure message. | Airtool Pi |
| **Beacon Flood** | Generating thousands of counterfeit 802.11 beacons to obscure legitimate APs. | N/A |
| **Denial-of-Service** | Exploiting CSMA/CA clear channel assessment (CCA) to make a channel appear busy. | Adapters supporting CW Tx mode |
| **De-authenticate Flood**| Flooding clients with forged de-auth packets to disconnect users. | AirJack |
| **Routing Attacks** | Distributing malicious routing information. | RIP protocol; wormhole/sinkhole |
| **Authenticate Flood** | Sending forged authenticates from random MACs to fill the target AP's association table. | AirJack |
| **ARP Cache Poisoning** | Creating many attack vectors via forged ARP responses. | N/A |
| **Power Saving Attacks** | Transmitting spoofed TIM/DTIM to a power-saving client, leaving it vulnerable to DoS. | N/A |
| **TKIP MIC Exploit** | Generating invalid TKIP data to exceed the AP's MIC error threshold, suspending WLAN service. | N/A |

## 5. Authentication Attacks

The objective is to steal client identity, personal info, and login credentials to gain unauthorized access.

| Type of Attack | Description | Method / Tools |
| :--- | :--- | :--- |
| **PSK Cracking** | Recovering a WPA PSK from captured key handshake frames using dictionary attacks. | Cowpatty, Fern WiFi Cracker |
| **LEAP Cracking** | Recovering credentials from 802.1X LEAP packets using dictionary tools to crack the NT password hash. | Asleap, THC-LEAPcracker |
| **VPN Login Cracking** | Gaining IPsec/PPTP credentials via brute-force attacks on VPN auth protocols. | ike_scan, IKECrack, THC-pptp-bruter |
| **Domain Login Cracking**| Recovering Windows logins by cracking NetBIOS password hashes. | John the Ripper, L0phtCrack |
| **Key Reinstallation** | Exploiting the 4-way handshake (KRACK). | Nonce reuse technique |
| **Identity Theft** | Capturing user identities from cleartext 802.1X Identity Response packets. | Packet capturing tools |
| **Shared Key Guessing** | Attempting 802.11 shared key auth with vendor default or cracked keys. | WEP cracking tools, Wifite |
| **Password Speculation**| Repeatedly attempting 802.1X auth using a captured identity to guess the password. | Password dictionary |
| **Application Login Theft**| Capturing credentials from cleartext application protocols. | Ace Password Sniffer, dsniff |

## 6. Specialized Wireless Attacks

### Honeypot AP Attack
When multiple WLANs coexist, a user's device probes for specific SSIDs. An attacker sets up an unauthorized **Rogue AP** with high-gain antennas using the same SSID. These "honeypot" APs transmit a stronger beacon signal, forcing the victim's NIC to connect to the rogue AP instead of the legitimate one, revealing usernames and passwords.

### Wormhole Attack
Exploits dynamic routing protocols like DSR and AODV. The attacker locates themselves strategically, advertising that their malicious node (M) has the shortest route.
* **Mechanism:** Source (S) sends an RREQ. The attacker sniffs it and forwards it via a direct tunnel to Destination (D) before the legitimate RREQ arrives. The same is done for the RREP.
* **Result:** A fake direct link is established between S and D via the attacker's tunnel, allowing real-time manipulation of application data.

### Sinkhole Attack
A variant of the selective forwarding attack. The attacker advertises a compromised node as the shortest route to the base station.
* Attracts neighboring nodes with fake routing paths and performs data forging.
* Can be combined with a wormhole attack to occupy all network traffic and tunnel it to the base station. Complex to detect and affects upper OSI layers.

### Inter-Chip Privilege Escalation / Wireless Co-Existence Attack
Exploits underlying vulnerabilities in "combo chips" that handle both Bluetooth and Wi-Fi. 
* Attackers leverage these combo chips to exploit one chip to steal data from the other (lateral movement).
* Example: A Bluetooth chip directly captures credentials or manipulates traffic going through the Wi-Fi chip during resource sharing, leading to privilege escalation at the chip boundaries.
