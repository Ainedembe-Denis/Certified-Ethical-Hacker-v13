## 1. Wireless Terminology

A wireless network is an unbounded data communication system that uses radio-frequency technology to communicate with devices using electromagnetic (EM) waves.

| Term | Description |
| :--- | :--- |
| **Global System for Mobile Communications (GSM)** | A universal system used for mobile data transmission in wireless networks worldwide. |
| **Bandwidth** | The amount of information that may be broadcast over a connection; refers to data transfer rate measured in bps. |
| **Access Point (AP)** | Connects wireless devices to a wireless/wired network via standards like Wi-Fi/Bluetooth; acts as a switch/hub between wired LAN and wireless network. |
| **Basic Service Set Identifier (BSSID)** | The MAC address of an access point (AP) or base station setting up a basic service set (BSS). |
| **ISM Band** | Industrial, scientific, and medical (ISM) band; frequencies used by international communities. |
| **Hotspot** | Places where wireless networks are available for public use. |
| **Association** | The process of connecting a wireless device to an AP. |
| **Service Set Identifier (SSID)** | A 32-alphanumeric-character unique identifier for a WLAN. |
| **Orthogonal Frequency-Division Multiplexing (OFDM)** | Digital modulation splitting a signal into multiple orthogonal carrier frequencies; produces higher bit rates than parallel channel operation. |
| **MIMO-OFDM** | Multiple Input, Multiple Output OFDM. Influences spectral efficiency of 4G/5G; reduces interference and increases channel robustness. |
| **Direct-Sequence Spread Spectrum (DSSS)** | A spread spectrum technique multiplying the original data signal with a pseudo-random noise-spreading code; protects against interference or jamming. |
| **Frequency-Hopping Spread Spectrum (FHSS)** | Also known as FH-CDMA. Rapidly switches a carrier among many frequency channels using a pseudorandom sequence; prevents unauthorized interception/jamming. |

### Advantages & Disadvantages of Wireless Networks

**Advantages:**
* Fast and easy installation without wiring.
* Provides connectivity in areas where cables are difficult to lay.
* Accessible from anywhere within the range of an AP.
* Constant Internet access in public spaces (airports, cafes).

**Disadvantages:**
* Security may not meet expectations.
* Bandwidth suffers as the number of devices increases.
* Upgrades may require new wireless cards/APs.
* Electronic equipment can cause interference.

## 2. Types of Wireless Networks

### 1. Extension to a Wired Network
An AP connects wireless clients to a wired LAN, allowing wireless access to LAN resources.
* **Software APs (SAPs):** Connected to a wired network, running on a computer with a wireless NIC.
* **Hardware APs (HAPs):** Dedicated hardware supporting most wireless features.

### 2. Multiple Access Points
Connects computers wirelessly using multiple APs or extension points. The wireless area of each AP must overlap its neighbor’s area to provide seamless **roaming**. Some manufacturers develop extension points acting as wireless relays.

### 3. LAN-to-LAN Wireless Network
APs provide wireless connectivity to local computers, and local computers on different networks can be interconnected using hardware APs.

### 4. 3G/4G/5G Hotspot
A wireless network type that provides Wi-Fi access to Wi-Fi-enabled devices via cellular data.

## 3. Wireless Standards

IEEE 802.11 started in 1997 with 1/2 Mbps in the IR and 2.4-GHz ISM band and has rapidly evolved.

| :--- | :--- | :--- | :--- | :--- |

| **802.11ax (Wi-Fi 6)** | 2.4 to 5 | 1024-QAM | 2400 | 240 |
| **802.11b** | 2.4 | DSSS | 1, 2, 5.5, 11 | 35 – 140 |
| **802.11be (Wi-Fi 7)** | 2.4, 5, 6 | QAM | 3000 | 120 |
| **802.11d** | \- | \- | \- | \- |
| **802.11e** | \- | \- | \- | \- |
| **802.11g** | 2.4 | OFDM | 6, 9, 12, 18, 24, 36, 48, 54 | 38 – 140 |
| **802.11i** | \- | \- | \- | \- |
| **802.11n** | 2.4, 5 | MIMO-OFDM | 54 – 600 | 70 – 250 |

### Detailed Descriptions:
* **802.11a:** Operates in 5 GHz; high max speed but more sensitive to walls/obstacles.
* **802.11ax (Wi-Fi 6):** Up to 9.6 Gbps; uses OFDMA; features BSS Coloring and TWT; ideal for dense environments.
* **802.11b:** Extended in 1999; 2.4 GHz using DSSS.
* **802.11be (Wi-Fi 7):** Up to 30 Gbps; uses multilink operation (MLO) to aggregate channels; designed for IoT, VR/AR, and ultrahigh-speed Internet.
* **802.11d:** Supports regulatory domains (can be set in the MAC layer).
* **802.11e:** Defines QoS mechanisms for time-sensitive applications (voice, VoIP, video).
* **802.11g:** Extension of 802.11b; 54 Mbps using OFDM on 2.4 GHz.
* **802.11i:** Improves security by implementing TKIP and AES.
* **802.11n:** Introduces MIMO antennas; works in both 2.4 GHz and 5 GHz.
* **802.11ah (Wi-Fi HaLow):** Uses 900 MHz bands for extended-range IoT communication.
* **802.11ac:** 5 GHz Gigabit networking; faster and more reliable than 802.11n.
* **802.11ad:** Works on the 60 GHz spectrum for extremely high propagation speeds.
* **802.12:** Demand priority protocol; 100 Mbps Ethernet speed.
* **802.15 (WPAN):** Standards for Wireless Personal Area Networks.
* **802.15.1 (Bluetooth):** Short distance data exchange.
* **802.15.4 (ZigBee):** Mesh network transmitting long-distance data at low data rates (250 Kbps) for long battery life.
* **802.15.5:** Deploys on full-mesh or half-mesh topology.
* **802.16 (WiMAX):** Fixed broadband wireless metropolitan access networks (MANs) using point-to-multipoint architecture.

## 4. Service Set Identifier (SSID)

* A case-sensitive, human-readable unique identifier of a WLAN, 32 alphanumeric characters in length.
* Identifies and locates 802.11 networks.
* By default, it is part of the frame header of packets sent over a WLAN.
* **Security Concern:** SSIDs are broadcast in plaintext (unless hidden), making it easy to obtain. It is not an effective security mechanism on its own. Using default SSIDs (often the vendor's name) creates vulnerabilities. Non-secure access modes allow clients to connect using a blank SSID or "any".

## 5. Wi-Fi Authentication Process

### Pre-Shared Key (PSK) Mode
Also known as **WPA-PSK** or **WPA2-PSK**.
* Uses a single shared password for authentication.
* Popular in homes and small offices due to simplicity.
* **Process:** Client attempts connection → AP sends challenge text → Client encrypts challenge text and sends back to AP → AP decrypts and authenticates if correct → Client connects.
* **Weakness:** Security depends entirely on the complexity and secrecy of the pre-shared key.

### Centralized Authentication Mode (802.1X / Enterprise Mode)
Also known as **WPA/WPA2-Enterprise**.
* Uses a centralized authentication server, typically a **RADIUS** (Remote Authentication Dial-In User Service) server.
* Each user is assigned unique credentials (username/password or digital certificate).
* **Process:** Client requests connection → AP sends EAP-Request → Client sends EAP-Response with identity → AP forwards identity to RADIUS server via uncontrolled port → RADIUS requests auth mechanism → Client responds to RADIUS via AP → RADIUS sends encrypted auth key to AP if acceptable → AP sends global auth key encrypted with a per-station unicast session key to Client.
* **Strength:** High security for environments with many users (corporate offices, government).

## 6. Types of Wireless Antennas

Antennas convert electrical impulses into radio signals and vice versa.

| Type | Description | Image Summary |
| :--- | :--- | :--- |
| **Directional Antenna** | Broadcasts and receives radio waves from a single direction. Reduces interference and improves transmission/reception. | Directed beam, often flat or sectoral. |
| **Omnidirectional Antenna** | Radiates EM energy in all directions (360° horizontal radiation pattern). Strong uniformly in two dimensions but less strong in the third. Effective for mobile receivers (e.g., radio stations). | Standard stick/pole antenna. |
| **Parabolic Grid Antenna** | Uses satellite dish principle but with a wire grid. Achieves very long-distance (up to 10 miles) highly focused radio beams. Useful for attackers to gather more bandwidth, higher power, and perform Layer-1 DoS or MITM attacks. | Dish made of wire grids. |
| **Yagi Antenna (Yagi-Uda)** | Unidirectional antenna (10 MHz to VHF/UHF) with high gain and low SNR. Concentrates radiation in an end-fire pattern using a reflector, dipole, and directors. | Fishbone-style antenna. |
| **Dipole Antenna** | A straight electrical conductor (half a wavelength) connected at the center of the RF feed line. Bilaterally symmetrical (balanced antenna). | Standard split-pole antenna. |
| **Reflector Antennas** | Uses a parabolic mirror (dish) to concentrate EM energy at a focal point. Large reflectors multiply wavelength for higher gain, though expensive. | Solid parabolic dish. |
