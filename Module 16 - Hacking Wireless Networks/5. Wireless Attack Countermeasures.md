## 1. Wireless Security Layers

A wireless security mechanism has **six layers**. This layered approach increases the scope of preventing network compromises.

| Security Layer | Description |
| :--- | :--- |
| **Wireless Signal Security** | Continuously monitor and manage the RF spectrum. A Wireless Intrusion Detection System (WIDS) analyzes the RF spectrum and generates alarms for unauthorized devices, increased bandwidth, or RF interferences. |
| **Connection Security** | Per frame/packet authentication provides protection against MITM attacks and prevents sniffing. |
| **Device Security** | Vulnerability and patch management for the security infrastructure. |
| **Data Protection** | Utilizing encryption algorithms such as WPA3, WPA2, and AES. |
| **Network Protection** | Strong authentication (e.g., 802.1X/RADIUS) ensures only authorized users gain access. |
| **End-User Protection** | Personal firewalls installed on end-user systems prevent attackers from accessing files even if they associate with the AP. |

## 2. Defense Against Specific Wireless Attacks

### Defense Against WPA/WPA2/WPA3 Cracking
* **Use Strong Passwords:** 12-16 characters minimum, complex and difficult to guess.
* **Client Settings:** Use WPA2 with AES/CCMP only. Validate server settings, and regenerate keys for new connections.
* **Additional Controls:** Implement VPNs, IPsec, SSL/TLS, and NAC/NAP solutions for end-user connectivity control.
* **Disable TKIP:** Ensure only AES is used in router settings.
* **MAC Address Filtering:** Allow only specific MAC addresses to connect.
* **Upgrade to WPA3:** Protects against brute-force attacks via SAE.
* **Disable Vulnerable Services:** Turn off Remote Management and WPS (vulnerable to PIN brute force).
* **Regular Updates:** Patch router firmware regularly.
* **Reduce Signal Range:** Adjust transmission power and place the router centrally.
* **Enable WPA3-SAE & Disable Transition Mode:** Prevents downgrade attacks to WPA2.

### Defense Against KRACK Attacks
* Update all routers and Wi-Fi devices with the latest security patches.
* Avoid public Wi-Fi; browse only secured websites (HTTPS).
* Disable fast roaming / 802.11r protocol if not needed.
* Employ the **EAPOL-key replay counter** to ensure the AP recognizes only the latest counter value.
* Use a backup wired connection when a KRACK vulnerability is detected.

### Defense Against aLTEr Attacks (LTE Hijacking)
* Encrypt DNS queries with proper security standards (e.g., **Cisco Security Connectors** using Cisco Umbrella).
* Use only trusted DNS resolvers.
* Use **DNS over TLS (DoT)** or **DNS over DTLS** for traffic integrity.
* Implement **RFC 7858/RFC 8310** to prevent DNS spoofing.
* Use the **DNSCrypt** protocol.
* Deploy mobile device tools (e.g., **Zimperium**) to detect phishing.
* Use **eSIM** technology and deploy secure SIM cards with OTA updates.

## 3. Detection and Blocking of Rogue APs

Rogue APs provide backdoor access and must be actively hunted and neutralized.

### Detection Methods
* **RF Scanning:** Repurposed APs act as RF sensors to warn administrators of rogue devices.
* **AP Scanning:** APs with neighboring AP detection expose data via MIBs and web interfaces.
* **Wired Side Inputs:** Network management software detects connected devices via Telnet, SNMP, and CDP.
* **Authorized AP Comparison:** Use tools like *AirMagnet WiFi Analyzer* to compare detected APs against a whitelist.
* **Signal Strength Analysis:** Use tools like *Ekahau Survey* to identify physically close but unauthorized APs.
* **MAC Filtering:** Cisco WLAN Controllers provide built-in rogue AP detection via MAC monitoring.

### Blocking Methods
* Deny wireless service by launching a **DoS attack** on the rogue AP.
* Physically locate the AP and **block its switch port**.
* Use a **WIPS** to automatically perform blocking actions.
* Implement **802.1X authentication** so only legitimate APs and users can connect.
* Segment the network to isolate critical resources.

## 4. Wireless Intrusion Prevention Systems (WIPS)

A WIPS monitors the radio spectrum for unauthorized APs and automatically implements countermeasures.

### WIPS Deployment Components (e.g., Cisco WIPS)
* **APs in Monitor Mode:** Constant channel scanning, attack detection, and packet capture.
* **Mobility Services Engine (MSE):** Central point of alarm aggregation from all controllers and monitor-mode APs; archives forensic files.
* **Local Mode APs:** Provide wireless service while conducting time-sliced rogue/location scanning.
* **WLAN Controllers:** Forward attack info from APs to the MSE and distribute configurations.
* **Wireless Control System:** Configures the WIPS service on the MSE, views alarms, forensics, and threat encyclopedias.

### Wi-Fi Security Auditing & IPS Tools
* **Cisco Adaptive Wireless IPS:** Dedicated monitoring, integrated with Cisco Unified Wireless Network.
* **WatchGuard Wi-Fi Cloud WIPS:** Defends against rogue APs, evil twins, and DoS attacks with near-zero false positives.
* **Extreme AirDefense**
* **Arista WIPS**
* **SonicWall Wireless Network Manager**
* **FortiGate NGFW**

## 5. Best Practices for Wireless Security

### Configuration Best Practices
* Change default SSIDs and router IP addresses.
* Disable SSID broadcasts (use SSID cloaking) and remote router login.
* Close unused ports.
* Segregate guest networks from the private network.
* Disable DHCP; rely on static IP addresses.
* Disable SNMP or use least privilege settings.
* Adjust transmission power to limit range strictly to required premises.
* Implement IPsec over wireless.

### Authentication Best Practices
* Enable **WPA3**; fallback to **WPA2-AES** (never WEP/TKIP).
* Use **802.1X/RADIUS** for enterprise environments to provide individual credentials.
* Implement **MFA (Multifactor Authentication)**.
* For 802.1X, manage digital certificates properly with strong encryption.
* Enable server verification on the client side using 802.1X to prevent MITM attacks.
