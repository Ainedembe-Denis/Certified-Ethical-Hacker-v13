## 1. Search Engine Footprinting

Search engines (Google, Bing, Yahoo, Ask, Aol, Baidu, Yandex, WolframAlpha, DuckDuckGo) use automated crawlers to scan websites, index results, and return Search Engine Results Pages (SERPs).
- They extract technology platforms, employee details, login pages, intranet portals, and contact info.
- This helps attackers perform social engineering and advanced system attacks.
- *Tip for Ethical Hackers:* You can request search engines to remove deleted or sensitive pages from their indexed cache.

## 2. Advanced Google Hacking Techniques

Google hacking uses advanced search operators to create complex queries that extract sensitive or hidden info, bypassing irrelevant data.

*Syntax:* `operator:search_term` (Do not enter any spaces between the operator and the query).

**Popular Google Advanced Search Operators:**
- `site:` Restricts results to a specified site/domain (e.g., `games site:certifiedhacker.com`).
- `allinurl:` Restricts results to pages containing all query terms in the URL (e.g., `allinurl: google career`).
- `inurl:` Restricts results to pages containing the specified word in the URL (e.g., `inurl: copy site:www.google.com`).
- `intext:` Displays results containing the specific keyword within the body text (e.g., `intext:"vpn configuration"`).
- `allintitle:` Restricts results to pages containing all query terms in the title (e.g., `allintitle: detect malware`).
- `intitle:` Restricts results to pages containing the specified term in the title (e.g., `malware detection intitle:help`).
- `inanchor:` Restricts results to pages containing query terms in the anchor text of links (e.g., `Anti-virus inanchor:Norton`).
- `allinanchor:` Restricts results to pages containing all query terms in anchor text (e.g., `allinanchor: best cloud service provider`).
- `cache:` Displays Google's cached version of a webpage instead of the current version (e.g., `cache:www.eff.org`).
- `link:` Searches websites or pages that contain links to the specified website (e.g., `link:www.googleguide.com`). *Cannot be combined with regular keyword search.*
- `related:` Displays websites similar or related to the specified URL (e.g., `related:www.microsoft.com`).
- `info:` Finds information for the specified web page (e.g., `info:gothotel.com`).
- `location:` Finds information for a specific location (e.g., `location: 4 seasons restaurant`).
- `filetype:` Searches for results based on a file extension (e.g., `jasmine:jpg`).
- `source:` Displays info from a specific website in Google News (e.g., `Malware news source:"Hacker News"`).
- `phonebook:` Finds residential/business phone numbers (e.g., `phonebook:Sundar Pichai`).
- `before:` Filters search results published before a specified date (e.g., `ransomware before:2020-06-29`).
- `after:` Finds info published after a certain date (e.g., `site:wikipedia.org after:2023-01-01 artificial intelligence`).

## 3. What Hackers Find with Google Hacking

By locating specific strings of text, attackers identify vulnerable sites and launch attacks like buffer overflows and SQL injections. They can extract:
- Error messages containing sensitive info
- Files containing passwords
- Sensitive directories and logon portals
- Network/vulnerability data (IDS, firewall logs, configs)
- Advisories, server vulnerabilities, and software versions
- Web application source code
- Unprotected IoT devices and control panels
- Hidden web pages (intranet and VPN services)

*Example:* `intitle:intranet inurl:intranet +intext:"human resources"` finds sensitive HR intranet info for social engineering.

## 4. AI Automation with ShellGPT

Attackers leverage AI (like ShellGPT) to automate advanced Google hacking.

**Prompt Example:** *"Use filetype search operator to obtain pdf files on the target website eccouncil.org and store the result in the recon1.txt file"*

**Generated Shell Command:**
```bash
lynx --dump "http://www.google.com/search?q=site:eccouncil.org+filetype:pdf" | grep "http" | cut -d "=" -f2 | grep -o "http[^&]*" > recon1.txt
```
*Breakdown:*
- `lynx --dump`: Accesses Google search results in dump mode.
- `grep "http"`: Filters lines with "http".
- `cut -d "=" -f2`: Splits the line at "=" and grabs the second field.
- `grep -o "http[^&]*"`: Searches for the URL pattern.
- `> recon1.txt`: Redirects output to file.

## 5. Google Hacking Database (GHDB) & Exploit-DB

**GHDB** (https://www.exploit-db.com/google-hacking-database) is a subset of Exploit-DB containing "Google Dorks" used to uncover sensitive info inadvertently exposed on the web.
- **Finds:** Sensitive files (configs, DB dumps), exposed directories, error messages, and vulnerable devices.
- **GHDB Categories:** Footholds, Files Containing Usernames/Passwords/Juicy Info, Web Server Detection, Vulnerable Servers, Login Portals, Online Devices, etc.
- **Uses:** Reconnaissance, exploiting misconfigurations, finding vulnerable systems, credential harvesting, and identifying open ports.
- **SearchSploit:** A command-line tool allowing offline searches of the locally checked-out Exploit-DB repository, ideal for air-gapped network assessments.

## 6. VPN Footprinting through Google Hacking

Google dorks can identify VPN servers, login portals, and directories containing VPN keys. 

**AI Automation Example (ChatGPT):**
Prompt: *"Use inurl search operator to obtain the Fortinet VPN login pages"*

**Command:**
```bash
lynx -dump "http://www.google.com/search?q=inurl:%22remote+login%22+fortinet+OR+fortigate+OR+%22ssl+vpn%22" | grep "http" | cut -d "=" -f2 | grep -o "http[^&]*"
```
*This searches for web pages containing "remote login" in the URL and "Fortinet", "Fortigate", or "ssl vpn" in the content, then extracts the URLs.*

## 7. Footprinting through Shodan

**Shodan** (https://www.shodan.io) is a search engine that enables attackers to find internet-connected devices (routers, servers, IoT, SCADA). 
- It detects vulnerable devices and networks.
- A search for VoIP and VPN can deliver VPN-related info and open ports.

## 8. Other Search Engine Techniques

- **Google Advanced Search & Reverse Image Search:** 
  - *Advanced Search* (`/advanced_search`): Precise searching without remembering operators. Allows specifying exact phrases, exclusion words, etc.
  - *Reverse Image Search:* (`/advanced_image_search` or TinEye, Yahoo/Bing Images). Allows uploading an image or pasting a URL to track the original source of photographs, profile pictures, or memes.
- **Video Search Engines:** 
  - Crawl for video content on YouTube, Google/Yahoo/Bing Videos. 
  - Attackers analyze videos to gather hidden info (date/time/thumbnails) using tools like YouTube Metadata, YouTube DataViewer, MW Metadata, EZGif, and VideoReverser.com.
- **Meta Search Engines:** 
  - Send queries to multiple search engines simultaneously (e.g., Startpage, MetaGer, eTools.ch). 
  - They rank results, filter duplicates, and provide privacy by hiding the user's IP.
- **FTP Search Engines:** 
  - Search unsecured FTP servers (e.g., NAPALM FTP Indexer, FreewareWeb FTP File Search, Mamont, Globalfilesearch.com) to find critical files like business strategies, tax/financial docs, employee records, and licensed software.
- **IoT Search Engines:** 
  - Crawl for publicly accessible IoT devices (Shodan, Censys, ZoomEye). 
  - Attackers can gain control of unsecured SCADA systems, CCTV cameras, and appliances to establish backdoors.
