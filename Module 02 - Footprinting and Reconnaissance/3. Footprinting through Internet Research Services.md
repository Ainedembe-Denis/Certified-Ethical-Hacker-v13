## 1. Finding TLDs and Sub-domains

Top-Level Domains (TLDs) expose a company's public presence. Sub-domains (often used for testing or internal departments) are typically less secure and more vulnerable to exploitation. Identifying them reveals source code, internal webservers, and private functions.
- **Google Operator:** `site:microsoft.com -inurl:www`

**Sub-domain Discovery Tools:**
- **Netcraft** (netcraft.com): Obtains all sub-domains related to the target domain.
- **DNSdumpster** (dnsdumpster.com): Domain research tool that discovers hosts, IPs, and DNS servers related to the domain.
- **Pentest-Tools Find Subdomains** (pentest-tools.com): Discovers sub-domains, IP addresses, OS, HTTP servers, technology used, and page titles.

**AI Automation Examples:**
*Example 1: Using `dig` via ChatGPT Prompt*
```bash
dig +short google.com NS | xargs -I{} dig +nocmd +noall +answer @{} google.com A | grep -E 'CNAME|A|AAAA'
```
*Explanation:* Queries authoritative NS records, then passes each to a new `dig` command to find A records (IP addresses associated with subdomains).

*Example 2: Using `Sublist3r` via ChatGPT Prompt*
```bash
sublist3r -d eccouncil.org -o eccouncil_subdomains.txt
```
*Explanation:* Uses Sublist3r to search for subdomains and outputs them to a text file.

## 2. Extracting Website Information (Archive.org)

**Archive.org (Wayback Machine):** Explores archived versions of websites since their creation. Attackers retrieve removed web pages, audio, video, images, and text to perform phishing and web application attacks.

**Automation via Photon:**
- Retrieve Wayback URLs: `photon.py -u <URL> -l 3 -t 200 --wayback`
- Retrieve archived URLs directly: `python photon.py -u <URL> -l 3 -t 200 --only-urls`

## 3. People Search and Job Sites

**People Search Services:**
Provide personal details (names, addresses, DOB, photos, profession, family/friends, criminal checks, emails). Attackers use this to obtain bank/credit card details or build social engineering attacks.
- *Examples:* Spokeo, Intelius, pipl, BeenVerified, Whitepages, Instant Checkmate, PeekYou.
- *Spokeo (spokeo.com):* Gathers phone numbers, address history, social profiles, and court records.

**Job Sites:**
Reveal OS, software versions, infrastructure, databases, and key employee emails through job requirements. Resumes reveal past technical history.
- *Examples:* Dice, LinkedIn, Glassdoor, Simply Hired.

## 4. Dark Web Footprinting

- **Surface Web:** Indexed, normal browsers.
- **Deep Web:** Hidden/unindexed (government DBs). Accessed via Tor or WWW Virtual Library.
- **Dark Web (Darknet):** Deeper layer for anonymous navigation. Requires Tor Browser or ExoneraTor.

**Dark Web Searching:**
Attackers gather confidential info (credit cards, passports, medical records, SSNs) to launch attacks.

**Advanced Search Parameters:**
- Personal profiles: `"John Doe" site:facebook.com OR site:linkedin.com`
- Scientific publications: `"John Doe" site:scholar.google.com`
- Court records: `"John Doe" court records`
- Member directories: `"John Doe" site:example.com "employee directory"`
- Medical / Location records: `"John Doe" medical records`

**Dark Web Dorks (Tor Browser):**
| Information | Search Query |
| :--- | :--- |
| Sensitive PDFs | `filetype:pdf site:onion confidential` |
| Passwords in Configs | `inurl:config filetype:txt password` |
| Financial Docs | `filetype:xlsx site:onion financial` |
| Database Dumps | `filetype:sql site:onion dump` |
| Email Lists | `filetype:csv site:onion email` |
| Login Credentials | `intitle:"login credentials" filetype:docx` |
| Server Configs | `filetype:xml inurl:config server` |
| Private Keys | `filetype:key site:onion private` |

## 5. Determining the Operating System

**OS Fingerprinting:** Detecting the OS and connected devices (routers, servers, IoT) to identify vulnerabilities and exploits.
- **Netcraft:** "What's that site running?" feature identifies the OS running at each associated site.
- **Shodan (shodan.io):** Searches for connected devices based on city, country, coordinates, hostname, OS, and IP. Integrates with Exploit DB and Metasploit.
- **Censys (censys.io):** Discovers assets exposed to the Internet, revealing OS, IPs, protocols, and locations.

## 6. Competitive Intelligence Gathering

The non-interfering, legal process of analyzing competitors. Helps attackers build hacking strategies by determining establishment dates, strategies, decision-makers, and branch locations.

**Approaches:**
- **Direct:** Trade shows, social engineering of employees.
- **Indirect:** Websites, ads, support threads, patents, retail outlets, legal databases, financial filings.

**Information Resource Sites:**
- **EDGAR Database (sec.gov/edgar):** SEC corporate filings and time-sensitive corporate information.
- **D&B Hoovers (dnb.com):** Commercial database of 120 million business records.
- **LexisNexis (lexisnexis.com):** Legal, risk management, and public records database.
- **Business Wire (businesswire.com):** Full-text press release and multimedia distribution.
- **Factiva (dowjones.com):** Global news database from 33,000 licensed sources.

**Business Plans & Expert Opinions:**
- **MarketWatch, Wall Street Transcript, Euromonitor:** Market trends, financial news, CEO interviews, and demographic surveys.
- **Experian & Search Monitor:** Competitor marketing strategies, PPC ad tracking, and trademark use.
- **USPTO:** Patents and trademark registration.
- **SEMRush & SERanking:** Keyword research, AdWords tracking, and PPC competitor analysis.
- **ABI/INFORM Global & SimilarWeb:** Business databases and web traffic aggregators.

## 7. Other Internet Research Techniques

- **Finding Geographical Location:** 
  Tools like Google Earth, Google Maps, Apple Maps, Waze, and Wikimapia provide 3D street views, coordinates, and Wi-Fi network info. Attackers use this for dumpster diving, finding building entrances, security cameras, weak fences, and utility connections.
- **Gathering Info from Financial Services:** 
  Google Finance, MSN Money, Yahoo Finance, and Investing.com provide stock charts, market value, and press releases. Attackers target this data via malware, phishing, and service flooding.
- **Business Profile Sites:** 
  OpenCorporates, Crunchbase, and Corporationwiki reveal company locations, contact info, employee databases, and industry types.
- **Monitoring Targets Using Alerts:** 
  Google Alerts, X Alerts, and Giga Alerts automate notifications via email/SMS when new content matches specific terms, providing up-to-date intel on competitors and projects.
- **Tracking Online Reputation (ORM):** 
  Companies use ORM to be transparent and manage reputation. Attackers track this using tools like **Mention** (mention.com), **ReviewPush**, and **Reputology** to collect live reports on what is being said about the brand across social media, blogs, and news.
