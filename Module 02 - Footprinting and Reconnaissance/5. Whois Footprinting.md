## 1. Whois Lookup

Whois is a query and response protocol that listens on **TCP port 43**. It queries databases storing registered users or assignees of Internet resources (domain names, IP blocks, autonomous systems).
- **RIRs:** Regional Internet Registries maintain these databases, providing text records regarding assignees, registrants, and administrative info (creation/expiration dates).

**Information Returned by Whois Query:**
- Domain name details and Domain registrar
- Contact details of the domain owner
- Domain name servers
- NetRange
- Dates (creation, expiry, last updated)
- Domain status (available, registered, suspended)
- IP address information

*Attacker Usage:* Creates a map of the network, misleads domain owners via social engineering, and obtains internal network details.

**Regional Internet Registries (RIRs):**
- **ARIN** (https://www.arin.net): American Registry for Internet Numbers
- **AFRINIC** (https://www.afrinic.net): African Network Information Center
- **APNIC** (https://www.apnic.net): Asia Pacific Network Information Center
- **RIPE** (https://www.ripe.net): Réseaux IP Européens Network Coordination Centre
- **LACNIC** (https://www.lacnic.net): Latin American and Caribbean Network Information Center

## 2. Whois Data Models

There are three primary data models used to store and lookup Whois information:
1. **Thick Whois (Distributed Model):** Stores the complete Whois information from all the registrars for a particular set of data.
2. **Thin Whois (Centralized Model):** Stores only the name of the Whois server of the registrar of a domain, which in turn holds complete details on the data being looked up.
3. **Decentralized Whois:** Stores complete WHOIS information and has multiple independent entities to manage the WHOIS database.

## 3. Whois Lookup Results & Tools

Web services and applications are used to perform lookups by entering the target domain or IP address.
- **Web Services:** `https://whois.domaintools.com` and `https://www.tamos.com`
- **Batch IP Converter** (http://www.sabsoft.com): Provides info about an IP/hostname/domain (country, state, city, phone, fax, network provider, admin/tech contacts). It supports **Internationalized Domain Names (IDNs)** (non-English characters) and IPv6 addresses.
- **Other Tools:** WHOIS Domain Lookup, Active Whois.

## 4. Finding IP Geolocation Information

IP geolocation obtains the target's country, region/state, city, latitude/longitude, ZIP code, time zone, connection speed, ISP (hosting company), domain name, IDD country code, area code, weather station code, mobile carrier, and elevation.

**Why Attackers Use Geolocation:**
- Gather info via social engineering, surveillance, and non-technical attacks (dumpster diving, hoaxing, acting as a tech expert).
- Set up compromised web servers near the victim's location.
- Perform malicious activities specific to that area, infect with localized malware, or attempt unauthorized physical or network access.
- Launch social engineering attacks such as spamming and phishing.

**IP Geolocation Lookup Tools:**
- **IP2Location** (https://www.ip2location.com): Identifies a visitor's exact geographical location, connection speed, ISP, mobile carrier, and usage type using a proprietary IP address lookup database and technology.
- **Other Tools:** IP Location Finder, IP Address Geographical Location Finder.
