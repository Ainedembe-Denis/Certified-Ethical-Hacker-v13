## 1. Locating the Network Range

Finding the network range helps identify network topology, access control devices, OS, and live hosts.
- **Process:** Gather basic information about the organization. Enter the server IP address (found via Whois) into a Regional Internet Registry database search tool (e.g., ARIN Whois text box at https://www.arin.net/about/welcome/region). This yields the exact network range.
- **Private IP Blocks (IANA reserved):**
  - `10.0.0.0 – 10.255.255.255` (10/8)
  - `172.16.0.0 – 172.31.255.255` (172.16/12)
  - `192.168.0.0 – 192.168.255.255` (192.168/16)
- *Note:* Improperly setup DNS servers or running a traceroute can reveal the internal IP address of a gateway. Attackers typically use multiple tools to obtain this info (e.g., NetScanTools Pro, PingPlotter).

## 2. Traceroute

Traceroute tracks the path IP packets travel between two systems. It reveals the number of routers, round-trip time, IP addresses, DNS names of routers, geographic locations, and network affiliation.
- **How it works:** It exploits the **Time to Live (TTL)** field of the IP header. The sender sends a packet with TTL=1. The first router decrements the TTL by 1 (to 0), discards the packet, and sends an ICMP error message back to the sender (revealing the router's IP). The sender then sends TTL=2, and so on, until the destination returns a normal ICMP ping response.

**Types of Traceroute:**
- **ICMP Traceroute:** Windows default. 
  - *Command:* `C:\>tracert 216.239.36.10`
- **TCP/UDP Traceroute (Layer 4):** Used when devices block ICMP traceroute messages.
  - *Linux TCP Traceroute:* `sudo tcptraceroute www.google.com`
  - *Linux UDP Traceroute (Default):* `traceroute www.google.com`

## 3. Traceroute with AI

Attackers leverage AI (like ChatGPT) to automate tracerouting.

**Prompt Example:** *"Perform network tracerouting to discover the routers on the path to a target host www.certifiedhacker.com"*

**Generated Shell Command:**
```bash
traceroute www.certifiedhacker.com
```
*Explanation:* Initiates the traceroute tool to discover routers on the path by sending packets with increasing TTL values and analyzing responses from intermediate routers.

## 4. Traceroute Analysis & Tools

**Traceroute Analysis:**
By running multiple traceroutes to different IPs in a subnet, attackers can identify common intermediate hops (gateways/firewalls) and map the internal network.
- *Example:* 
  - `traceroute 1.10.10.20`, second to last hop is `1.10.10.1`
  - `traceroute 1.10.20.10`, third to last hop is `1.10.10.1`
  - *Result:* `1.10.10.1` is a key routing device.

**Traceroute Tools:**
Provide hop-by-hop tracing, historical analysis, ping plotting, port probing, reverse DNS, and geo-locations.
- **NetScanTools Pro** (https://www.netscantools.com): Offers ICMP, UDP, or TCP tracing. Locates the assigned country for each hop's IPv4 address.
- **PingPlotter** (https://www.pingplotter.com): Discovers hops, tracks latency/packet loss over time, and generates readable graphs to identify bandwidth bottlenecks, hardware faults, or WiFi interference.
- **Other Tools:** Traceroute NG, tracert.

## 5. Tracking Email Communications

Email tracking monitors messages using digitally time-stamped records to see when the target receives and opens a specific email. This info is used to build hacking strategies and social engineering attacks.

**Information Gathered:**
- **Recipient's System IP & Geolocation:** Distance calculated from the attacker.
- **Email Received, Read, and Read Duration:** When opened and time spent reading.
- **Proxy Detection:** Type of server used.
- **Links Checked:** Whether malicious links were clicked.
- **OS & Browser Info:** Used to find software loopholes for exploits.
- **Device Type & Path Travelled:** Tracks the exact path the email traveled via Mail Transfer Agents (MTAs).

## 6. Collecting Information from Email Header

The email header contains the sender details, routing info, addressing scheme, date, subject, and recipient.
- **Information contained:** Sender’s mail server, authentication systems, message ID, sender’s full name, date/time of receipt, and originating IP address.
- **Analysis:** By examining the header, an attacker traces the routing path taken by the email. The process to view headers varies by client (Outlook, Apple Mail, Tuta, Thunderbird, Mailbird, etc.).

---

## 7. Email Tracking Tools

These tools automate header analysis to extract sender identity, mail server, IP address, and geographical locations.
- **eMailTrackerPro** (http://www.emailtrackerpro.com): Analyzes headers to extract geographical location and IP. Allows saving past traces for later review.
- **IP2LOCATION’s Email Header Tracer** (https://www.ip2location.com): An open-source web service that traces back the target location and mail servers the email passed through.
- **Other Tools:** MxToolbox, Holehe, DNS Checker Email Header Analyzer, Social Catfish.
